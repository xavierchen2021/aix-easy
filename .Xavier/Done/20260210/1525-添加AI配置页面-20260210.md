# 添加AI配置页面

## 概述
在偏好设置中增加 "AI" 选项卡，允许用户配置 OpenAI 兼容接口的 API URL 和 API Key，为后续 AI 功能提供基础。

## 当前实现
```mermaid
graph TD
    A[SettingsView] --> B[Tabs: 通用, 提醒, 关于]
    B --> C[GeneralSettingsView]
    B --> D[ReminderSettingsView]
    B --> E[AboutSettingsView]
    
    F[FloatingButtonConfig] --> G[存储结构: Codable]
    H[FloatingButtonConfigManager] --> I[管理配置加载, 保存与更新]
```

## 方案
### 方案一：在现有配置体系中集成 AI 设置 (推荐方案 🚀)
1. **扩展模型层**：在 `FloatingButtonConfig` 中增加 `aiUrl` 和 `aiApiKey`。
2. **扩展管理层**：在 `FloatingButtonConfigManager` 中增加 `updateAiUrl` 和 `updateAiApiKey` 方法。
3. **扩展 UI 层**：
    - `SettingsView` 的 `tabs` 数组中增加 "AI" 项。
    - `SettingsView` 的 `switch` 逻辑中增加 `AISettingsView`。
    - 新建 `AISettingsView` 结构体，提供文本输入框。

```mermaid
graph TD
    subgraph Model
    Config[FloatingButtonConfig] -- 新增字段 --> URL[aiUrl]
    Config -- 新增字段 --> Key[aiApiKey]
    end
    
    subgraph Logic
    Manager[FloatingButtonConfigManager] -- 新增方法 --> updateURL[updateAiUrl]
    Manager -- 新增方法 --> updateKey[updateAiApiKey]
    end
    
    subgraph UI
    Settings[SettingsView] -- 新增Tab --> AITab[AI Tab]
    AITab --> AIView[AISettingsView]
    AIView --> URLInput[URL输入框]
    AIView --> KeyInput[Key输入框]
    end

    URLInput --> updateURL
    KeyInput --> updateKey
```

**优点：**
- 保持了现有设置系统的统一性。
- 配置持久化直接通过现有的 `AppDatabase` 处理，无需额外工作。

**缺点：**
- `FloatingButtonConfig` 正在变得越来越大。
