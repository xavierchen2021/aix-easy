# 修复休息提醒蒙版倒计时问题

## 概述
修复智能休息提醒功能中的三个核心问题：
1. 工作倒计时结束后，应该自动显示休息蒙版（状态2），但目前没有正确显示
2. 休息蒙版显示期间，倒计时会停住不动，无法继续倒计时
3. 蒙版显示期间，依然在监听键盘和鼠标活动，导致干扰倒计时逻辑

## 当前实现

## 方案

### 方案1:在蒙版显示期间完全停止InputMonitor监听 ⚠️

```mermaid
flowchart TD
    A[蒙版显示] --> B[调用inputMonitor.stopMonitoring]
    B --> C[停止键鼠事件监听]
    C --> D[只执行倒计时逻辑]
    D --> E[蒙版关闭]
    E --> F[调用inputMonitor.startMonitoring]
    F --> G[恢复键鼠事件监听]
```

**优点**：
- 从根本上阻止键鼠事件干扰
- 逻辑简单清晰

**缺点**：
- 频繁启停InputMonitor可能导致性能问题
- 重新启动监听可能需要时间,影响响应速度
- 可能丢失部分事件

2. [SmartReminderManager.swift](vscode://file/Volumes/Cache/X/Sources/Model/SmartReminderManager.swift:615) - startRestTimer方法, 确保监听已停止
3. [SmartReminderManager.swift](vscode://file/Volumes/Cache/X/Sources/Model/SmartReminderManager.swift:554) - handleReminderContinue方法, 在关闭蒙版后重新启动监听

### 方案3:临时禁用onActivityDetected回调 + 完善状态切换逻辑 ✅ 推荐方案

```mermaid
flowchart TD
    A[工作倒计时达到workDuration] --> B[showReminder显示状态1蒙版]
    B --> C[保存原onActivityDetected回调]
    C --> D[设置onActivityDetected为空闭包]
    D --> E{用户操作?}
    E -->|点击稍后休息| F[恢复回调,重置状态,关闭蒙版]
    E -->|无操作超过阈值| G[自动startRestTimer]
    G --> H[切换到状态2,显示休息倒计时]
    H --> I[启动restCountdownTimer<br/>每秒更新剩余时间]
    I --> J{用户操作?}
    J -->|点击我回来了| K[恢复回调,判断休息时长,关闭蒙版]
    J -->|倒计时结束| L[handleRestEnd切换到状态3]
    L --> M{用户操作?}
    M -->|点击开始工作| N[恢复回调,重置状态,关闭蒙版]
```

**优点**：
- 不需要频繁启停InputMonitor,保持监听器运行
- InputMonitor的lastActivityTime持续更新,不影响空闲判断
- 只是暂时禁用回调,不影响事件捕获
- 蒙版关闭时立即恢复回调,响应迅速
- 逻辑清晰,易于维护

**缺点**：
- 需要保存和恢复回调引用

## 任务总结与结论

### 问题分析
本次修复针对智能休息提醒功能的三个核心问题：
1. **蒙版显示期间依然监听键鼠活动**：InputMonitor的onActivityDetected回调在蒙版显示期间依然被触发，导致handleActivityDetected()被调用，干扰了倒计时逻辑
2. **休息倒计时会停住**：因为键鼠活动干扰，restCountdownTimer的更新逻辑受到影响
3. **状态1到状态2的切换不正确**：工作倒计时达到后，应该自动进入休息倒计时，但实现不完善

### 解决方案
采用方案3（推荐方案）：**临时禁用onActivityDetected回调 + 完善状态切换逻辑**

### 实现流程图
```mermaid
sequenceDiagram
    participant Timer as 定时器
    participant Manager as SmartReminderManager  
    participant Monitor as InputMonitor
    participant Overlay as ReminderOverlayWindow
    
    Timer->>Manager: 工作时长达到workDuration
    Manager->>Manager: showReminder()
    Manager->>Manager: 保存原回调到savedActivityCallback
    Manager->>Monitor: 设置onActivityDetected为空闭包
    Manager->>Overlay: 显示状态1蒙版
    
    Note over Monitor: InputMonitor继续监听<br/>但回调已禁用
    
    Timer->>Manager: handleTimerTick()
    Manager->>Manager: 检测到蒙版显示且overlayState=workComplete
    Manager->>Monitor: 检查timeSinceLastActivity()
    Monitor-->>Manager: 返回空闲时长
    Manager->>Manager: 空闲超过阈值,自动startRestTimer()
    Manager->>Overlay: 切换到状态2,显示休息倒计时
    Manager->>Manager: 启动restCountdownTimer
    
    loop 每秒更新
        Manager->>Overlay: 更新remainingTime
    end
    
    alt 用户点击按钮
        Overlay->>Manager: handleReminderContinue()
        Manager->>Monitor: 恢复savedActivityCallback到onActivityDetected
        Manager->>Overlay: 关闭蒙版
    else 倒计时结束
        Manager->>Manager: handleRestEnd()
        Manager->>Overlay: 切换到状态3
    end
```

### 关键修改点
1. **增加savedActivityCallback属性**（第23行）：保存原始回调引用
2. **showReminder()方法**（第467行）：显示蒙版时禁用回调
3. **startRestTimer()方法**（第615行）：确保回调已禁用
4. **handleReminderContinue()方法**（第554行）：关闭蒙版时恢复回调
5. **handleTimerTick()方法**（第280行）：增加蒙版显示判断，实现状态1到状态2的自动切换
6. **showRestOverlay()方法**（第674行）：优化定时器管理，确保倒计时不被中断
7. **stop()方法**（第140行）：停止时恢复回调，避免泄漏

### 核心优化
- **InputMonitor持续运行**：不需要频繁启停，lastActivityTime持续更新，空闲判断不受影响
- **回调管理机制**：通过临时禁用/恢复回调，优雅地控制活动检测的启用状态
- **状态切换完善**：在handleTimerTick()中增加对状态1蒙版的检测，实现自动切换到状态2
- **倒计时保护**：restCountdownTimer添加到RunLoop，确保不被其他事件中断
