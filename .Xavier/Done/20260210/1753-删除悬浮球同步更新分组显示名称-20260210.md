# 删除悬浮球同步更新分组显示名称

## 概述
当用户删除某个悬浮球时，由于数组索引会发生平移，必须同步更新分组信息中的成员索引，以确保 UI 显示的成员列表（如“分组1 (球1, 球2)”）保持正确。

## 当前实现
- `handleDeleteFloatingButton` 目前只处理了 Actions 和图标等字典映射的索引迁移。
- 忽略了 `buttonGroups` 中的 `memberIndices` 数组更新。

## 方案 (推荐方案 🚀)
1. 在 `AppDelegate.handleDeleteFloatingButton` 中遍历所有分组。
2. 逻辑：
   - 从 `memberIndices` 中移除被删除的 `buttonIndex`。
   - 将 `memberIndices` 中所有大于 `buttonIndex` 的值减 1。
   - 保存更新后的分组列表。

### 优点
- 保持数据一致性，修复 UI 显示滞后或错误的问题。

### 修改位置
- [AppDelegate.swift](vscode://file/Volumes/Cache/X/Sources/App/AppDelegate.swift:358) - 更新 `handleDeleteFloatingButton` 逻辑。

## 测试用例
1. 创建三个球 (A, B, C)，将 B, C 加入分组。
2. 删除 A 球。
3. 检查原 B 球（现 A 球）是否被移出分组（如果之前 A 在组里的话，本例中不适用），以及原 C 球（现 B 球）对应的分组显示是否变更为“球2”。

## 任务总结与结论
在 `AppDelegate.handleDeleteFloatingButton` 中补全了分组索引重排逻辑。现在删除任何悬浮球，都会自动校准所有剩余按钮在分组中的索引，确保 UI 个性化设置面板中的成员名称拼接保持正确。
