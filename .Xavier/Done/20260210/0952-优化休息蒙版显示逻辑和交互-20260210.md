# 优化休息蒙版显示逻辑和交互

## 概述
优化智能休息提醒的蒙版显示逻辑，统一两种休息触发场景的显示方式，并优化交互提示：
1. 两种触发场景使用同一个蒙版，但内容根据场景不同
2. 优化按钮悬停提示，根据休息时长显示不同内容
3. 统一点击行为，达到休息认定时间后点击都重置计时

## 已完成的核心修改

### 1. 增加触发类型标记
- 新增`RestTriggerType`枚举：区分工作达到和空闲检测两种触发场景
- 在ReminderOverlayWindow中增加`restTriggerType`属性
- 在startRestTimer方法中传递触发类型参数

### 2. 统一蒙版显示逻辑
- 两种触发场景显示相同的休息蒙版（状态2）
- 根据触发类型显示不同的消息：
  - 工作达到："您已工作足够时间，开始休息计时。"
  - 空闲检测："感知到您已离开，自动进入休息。"

### 3. 增加按钮悬停提示
- 在ReminderOverlayView中增加`buttonTooltip`计算属性
- 根据已休息时长动态生成提示：
  - `< restRecognitionTime`："还没有休息够时间，现在开始工作将延续之前的计时"
  - `>= restRecognitionTime`："休息好了，元气满满！开始工作吧"
- 悬停时显示提示文字，带有淡入淡出动画

### 4. 更新已休息时长
- 在restCountdownTimer中每秒更新`reminderOverlay.restDuration`
- 确保悬停提示能实时反映休息状态

### 5. 点击行为已统一
- 现有逻辑已经实现：达到休息认定时间后点击"我回来了"都会重置计时
- 无需额外修改
