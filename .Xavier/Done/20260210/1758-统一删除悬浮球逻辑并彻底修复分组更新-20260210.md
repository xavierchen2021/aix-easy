# 统一删除悬浮球逻辑并彻底修复分组更新

## 概述
修复删除悬浮球后分组信息未更新的问题。原因是 `AppDelegate` 中存在冗余的删除逻辑函数，且部分未被修复。本方案将统一删除逻辑并确保分组信息实时更正。

## 当前实现
- 存在 `handleDeleteFloatingButton` 和 `deleteFloatingButton` 两个重复功能的函数。
- 逻辑更新不完整。

## 方案 (推荐方案 🚀)
1. 提取核心逻辑到 `performDeleteFloatingButton(index: Int)`。
2. 包含完整的索引迁移、分组平移、通知发送。
3. 调用 `refreshAllWindows()` 确保 UI 实时重绘。

### 修改位置
- [AppDelegate.swift](vscode://file/Volumes/Cache/X/Sources/App/AppDelegate.swift:287) - 统一入口和核心方法。

## 测试用例
1. 从状态栏菜单删除中间的一个球，验证分组里的球号是否减少且重排。
2. 验证个性化设置窗口里的名称拼接是否正确。

## 任务总结与结论
通过提取实现在 `performDeleteFloatingButton` 核心方法，统一了两个删除入口（通知处理和右键菜单处理）的逻辑。现在无论何种方式删除悬浮球，都会同步执行分组成员索引平移，并发送全局配置变更通知，彻底解决了分组下拉框字符拼接错误的问题。
