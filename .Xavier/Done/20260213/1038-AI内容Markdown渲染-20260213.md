# AI内容Markdown渲染

## 概述
AI列表和大窗口的聊天内容支持 Markdown 解析和渲染，使用 swift-markdown-ui 库。

## 当前实现
```mermaid
sequenceDiagram
    participant AI as AI服务
    participant N as Note.content
    participant L as 列表视图
    participant W as 大窗口

    AI->>N: 流式追加文本(可能含markdown语法)
    N->>L: Text(content) ← 纯文本显示
    N->>W: Text(editedContent) ← 纯文本显示
    Note over L,W: 🔴 代码块/标题/列表等无法正确渲染
```

## 方案

### 🚀推荐方案：使用 swift-markdown-ui 库

```mermaid
sequenceDiagram
    participant AI as AI服务
    participant N as Note.content
    participant L as 列表视图
    participant W as 大窗口

    AI->>N: 流式追加文本(含markdown语法)
    N->>L: Markdown(content) ← 富文本渲染
    N->>W: Markdown(editedContent) ← 富文本渲染
    Note over L,W: ✅ 代码块/标题/列表/粗体等正确渲染
```

## 任务总结与结论
使用 swift-markdown-ui 库实现 AI 聊天内容的 Markdown 渲染，包括代码块、标题、列表、粗体、引用等。通过自定义暗色主题适配深色界面。流式传输中使用 Text 保证性能，完成后切换到 Markdown。Mermaid 流程图通过 WKWebView + mermaid.js CDN 渲染，并解决了 WebView 拦截滚动事件的问题。
