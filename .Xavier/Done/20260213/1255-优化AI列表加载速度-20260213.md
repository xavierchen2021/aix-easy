# 优化AI列表加载速度

## 概述
点击悬浮球打开AI列表时延迟明显，需要优化加载速度。

## 当前实现
```mermaid
sequenceDiagram
    participant U as 用户
    participant B as 悬浮球
    participant A as AppDelegate
    participant W as NoteWindow
    participant V as NoteListView
    participant M as Markdown

    U->>B: 点击
    B->>A: 通知
    A->>W: setMode(.ai) 🔴 重建整个视图树
    W->>V: 新建 NoteListView + NSHostingView
    V->>V: loadData → 同步查全表
    V->>M: 🔴 每个AI笔记都同步渲染Markdown
    M-->>V: 耗时阻塞
    V-->>W: 显示
```

## 方案

### 🚀推荐方案：列表惰性Markdown渲染
列表初始用 Text 显示，view 出现后异步切换到 Markdown 渲染。

修改位置：
[NoteListView.swift - AINoteItemView](vscode://file/Volumes/Cache/X/Sources/View/NoteListView.swift:308)

## 测试用例
点击悬浮球打开AI列表，观察是否立即出现。

## 任务总结与结论
列表初始用 Text 显示，onAppear 300ms 后切换 Markdown，消除打开延迟。
