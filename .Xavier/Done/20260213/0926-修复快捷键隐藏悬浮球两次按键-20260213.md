# 修复笔记窗口打开时快捷键隐藏悬浮球需按两次

## 概述
当笔记窗口打开时，同分组的其他悬浮球被隐藏。此时按全局快捷键隐藏悬浮球，会先恢复被隐藏的悬浮球（显示分支），再按才隐藏（隐藏分支）。期望：直接隐藏。

## 当前实现
```mermaid
sequenceDiagram
    participant U as 用户
    participant HK as 全局快捷键
    participant AD as AppDelegate
    participant NW as NoteWindow
    participant FW as FloatingWindows

    U->>FW: 点击悬浮球A（分组内有A,B）
    AD->>NW: 打开笔记窗口
    AD->>FW: hideGroupFloatingWindows → B.orderOut()
    Note over FW: A可见, B不可见(被笔记隐藏)

    U->>HK: 按快捷键想隐藏
    HK->>AD: toggleFloatingWindow()
    AD->>AD: allVisibleButtonsAreShown?
    Note right of AD: 🔴 B.isVisible=false → 返回false
    AD->>FW: 进入"显示"分支 → B.orderFrontRegardless()
    Note over FW: A,B都可见（不符合预期）

    U->>HK: 再按快捷键
    AD->>AD: allVisibleButtonsAreShown=true
    AD->>FW: 进入"隐藏"分支 → 全部orderOut
```

## 方案

### 🚀推荐方案：笔记窗口打开时视为"全可见"

当 `noteWindow.isVisible == true` 时，说明有分组悬浮球被笔记窗口临时隐藏。此时 `allVisibleButtonsAreShown` 应视为 `true`，直接进入隐藏分支。

```mermaid
sequenceDiagram
    participant U as 用户
    participant HK as 全局快捷键
    participant AD as AppDelegate
    participant NW as NoteWindow
    participant FW as FloatingWindows

    U->>FW: 点击悬浮球A
    AD->>NW: 打开笔记窗口
    AD->>FW: B.orderOut()

    U->>HK: 按快捷键想隐藏
    HK->>AD: toggleFloatingWindow()
    AD->>AD: noteWindow可见 → 视为全可见
    Note right of AD: ✅ allVisibleButtonsAreShown=true
    AD->>NW: noteWindow.orderOut()
    AD->>FW: A.orderOut(), B已经隐藏
    Note over FW: 全部隐藏（符合预期）
```

**优点**：
- 改动极小（1处判断条件）
- 逻辑清晰：笔记窗口打开 = 用户在使用中 = 视为可见状态

**修改位置**：
[AppDelegate.swift](vscode://file/Volumes/Cache/X/Sources/App/AppDelegate.swift:1238) — toggleFloatingWindow() 中 allVisibleButtonsAreShown 判断

## 测试用例
1. 打开笔记窗口（有分组悬浮球），按快捷键，验证一次即可隐藏所有悬浮球和笔记窗口
2. 再按快捷键，验证悬浮球全部恢复
3. 无笔记窗口时，快捷键正常 toggle

## 任务总结与结论
在 `toggleFloatingWindow()` 的 `allVisibleButtonsAreShown` 判断中加入笔记窗口状态检查。当笔记窗口打开时，视为所有悬浮球"可见"，直接进入隐藏分支。

修改位置：AppDelegate.swift toggleFloatingWindow() 方法，仅 1 处判断条件。
