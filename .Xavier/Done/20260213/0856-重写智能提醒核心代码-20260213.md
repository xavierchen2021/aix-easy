状态机严格对应用户描述：

```mermaid
sequenceDiagram
    participant U as 用户
    participant M as Manager
    participant I as InputMonitor
    participant A as AudioMonitor
    participant O as Overlay
    participant S as StatusBar

    Note over M: 【工作中】
    loop 每秒 tick
        M->>I: timeSinceLastActivity()
        alt 键鼠活动中(< 1s)
            M->>M: workTime += 1, idleTime = 0
        else 键鼠停止(≥ 1s)
            M->>M: idleTime += 1
            alt 空闲 > 20s
                M->>A: 检测音频
                alt 有音频持续5s
                    M->>M: idleTime=0, 暂停工作计时
                    Note over M: 【视频模式】
                end
            end
            alt 空闲 ≥ 阈值
                Note over M: 【离开中】
                M->>M: 休息认定计时开始
                alt 达到休息认定时间
                    M->>M: workTime=0(重置)
                    Note over M: 【已休息】
                end
            end
        end
        alt workTime ≥ workDuration
            M->>O: 弹蒙版 + 开始休息计时
            Note over M: 【蒙版中】
            alt 休息计时 ≥ restDuration
                M->>O: 自动关闭蒙版
                M->>M: workTime=0
            end
        end
        M->>S: 更新菜单栏
    end
    
    U->>O: 点击"稍后休息"
    O->>M: 关闭蒙版, workTime=0
```
