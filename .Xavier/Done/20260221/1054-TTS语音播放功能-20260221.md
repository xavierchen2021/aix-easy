# macOS TTS 语音播放功能

## 概述
利用 macOS 内置 TTS 能力，为翻译弹窗的原文/译文、语言学习的单词/例句添加语音朗读功能。

## 当前实现

```mermaid
graph TD
    subgraph 翻译弹窗
    A[原文区 TextEditor] --- B[译文区 Text]
    end
    
    subgraph 语言学习窗口
    C[词汇详情面板] --> D[单词标题]
    C --> E[所在句子]
    F[学习页] --> G[大字单词]
    F --> H[所在句子]
    end
    
    style A fill:#f90,color:#fff
    style B fill:#f90,color:#fff
    style D fill:#f90,color:#fff
    style E fill:#f90,color:#fff
    style G fill:#f90,color:#fff
    style H fill:#f90,color:#fff
```

标橙色的位置均需添加 🔊 语音播放按钮。项目中目前无任何 TTS 代码。

## 测试用例
1. 翻译弹窗：点击原文旁的 🔊 按钮，朗读原文（自动识别语言）
2. 翻译弹窗：点击译文旁的 🔊 按钮，朗读译文
3. 语言学习词汇详情：点击单词旁的 🔊 按钮，英语朗读单词
4. 语言学习词汇详情：点击例句旁的 🔊 按钮，英语朗读例句
5. 语言学习学习页：同上功能
6. 播放中再次点击，停止播放
7. 播放自然结束后按钮状态恢复

## 方案

### 🚀推荐 方案一：NSSpeechSynthesizer 轻量实现

```mermaid
graph TD
    A[新建 TTSService 单例] -->|NSSpeechSynthesizer| B[朗读文本]
    B --> C{语言判断}
    C -->|中文| D[zh-CN 语音]
    C -->|英文| E[en-US 语音]
    
    subgraph 翻译弹窗
    F["🔊 按钮(原文)"] --> A
    G["🔊 按钮(译文)"] --> A
    end
    
    subgraph 语言学习
    H["🔊 按钮(单词)"] -->|固定en-US| A
    I["🔊 按钮(例句)"] -->|固定en-US| A
    end
```

**优点**：
- API 简单（`NSSpeechSynthesizer`），macOS 10.0 起即支持
- 同步 API，无需 async/await
- 自动利用系统已下载的语音包

**缺点**：
- 语音质量依赖系统已下载的语音

### 方案二：AVSpeechSynthesizer 现代实现

与方案一相同架构，但使用 `AVSpeechSynthesizer`。

**优点**：
- 更现代的 API，更多语音选项
- 支持语速/音调等细粒度控制

**缺点**：
- 需要引入 AVFoundation 框架
- API 稍复杂（delegate 模式）
- macOS 上 AVSpeechSynthesizer 某些语音可能不如 NSSpeechSynthesizer 稳定

## 任务总结与结论

使用 `AVSpeechSynthesizer` 实现了 macOS TTS 功能：

```mermaid
graph TD
    A[TTSService 单例] -->|AVSpeechSynthesizer| B[语音合成]
    B --> C{语言判断}
    C -->|中文| D[用户选择的中文语音]
    C -->|英文| E[用户选择的英语语音]
    
    F[翻译弹窗] --> G["🔊原文 + 🔊译文"]
    H[语言学习] --> I["🔊单词 + 🔊例句"]
    J[设置面板] --> K[语音选择 + 试听]
    
    G --> A
    I --> A
    K --> A
```

**关键修复**：每个 `TTSSpeakButton` 使用 `@State` 的唯一 buttonId，通过 `TTSService.currentSpeakingId` 独立追踪播放状态。
