# 官方初始化菜单项

## 概述
在菜单栏添加「官方初始化」菜单项，点击后创建 3 个默认悬浮球（笔记/剪切板/常用文件），全部归入分组1。若已有同名分组则自动添加"(官方)"后缀避免冲突。

## 当前实现

```mermaid
flowchart TD
    A[首次启动] --> B[config = .default]
    B --> C[buttonCount=3, 3个默认分组]
    D[菜单栏] --> E[无官方初始化入口]
```

首次启动使用默认配置，但没有运行时重新初始化的入口。

## 方案

### 方案一：添加菜单项 + officialInit 方法 ✨推荐方案

```mermaid
flowchart TD
    A[菜单栏] --> B[点击「官方初始化」]
    B --> C[设置 buttonCount=3]
    C --> D[设置默认动作和颜色]
    D --> E{检查分组名冲突}
    E -->|无冲突| F[创建分组1/2/3]
    E -->|有冲突| G["创建分组1(官方)/2(官方)/3(官方)"]
    F --> H[分组1含索引0/1/2]
    G --> H
    H --> I[refreshAllWindows]
```

**优点：**
- 用户随时可重置为官方推荐配置
- 保留用户已有分组，新建额外分组避免冲突

**缺点：**
- 无

[AppDelegate.swift](vscode://file/Volumes/Cache/X/Sources/App/AppDelegate.swift:1063) — 新增 officialInit 方法

## 测试用例
1. 点击「官方初始化」→ 创建 3 个悬浮球（橙/绿/蓝），全部在分组1联动
2. 已有自建分组时点击「官方初始化」→ 新建的分组不与已有分组名冲突

## 任务总结与结论

在菜单栏添加「官方初始化」菜单项，点击后在现有悬浮球基础上额外添加最多 3 个官方默认球（橙-笔记/绿-剪切板/蓝-常用文件），创建分组1/2/3（冲突加"(官方)"后缀），新球全归入分组1联动。增加 10 个上限边界检查。

```mermaid
flowchart TD
    A[点击官方初始化] --> B{当前数量+3 > 10?}
    B -->|是| C[只添加剩余可用数量]
    B -->|否| D[添加3个官方球]
    C --> E[设置动作/颜色/分组]
    D --> E
    E --> F[refreshAllWindows]
```
