# 保存为知识分组选择

## 概述
当用户右键笔记点击「保存为知识」时，不再直接将笔记移动到默认知识分组（智库），而是弹出知识分组选择子菜单，让用户选择目标知识分组后，再将笔记移动到对应分组。

## 当前实现

```mermaid
sequenceDiagram
    participant U as 用户
    participant CM as 右键菜单
    participant NM as NoteManager
    participant DB as 数据持久化

    U->>CM: 右键笔记
    CM->>CM: 显示菜单项
    U->>CM: 点击「保存为知识」
    CM->>NM: toggleKnowledge(id)
    Note over NM: ⚠️ 直接移动到默认知识分组「智库」<br>无法选择目标分组
    NM->>NM: isKnowledge = true
    NM->>NM: groupId = defaultKnowledgeId
    NM->>DB: saveNotes()
```

当前问题：点击「保存为知识」后，笔记一律被移动到默认知识分组「智库」，用户无法选择将其归类到哪个知识分组。

## 方案

### 方案一：将「保存为知识」改为子菜单 ✨推荐方案

```mermaid
sequenceDiagram
    participant U as 用户
    participant CM as 右键菜单
    participant NM as NoteManager
    participant DB as 数据持久化

    U->>CM: 右键笔记
    CM->>CM: 显示菜单项
    U->>CM: 悬停「保存为知识」
    CM->>CM: 展开知识分组子菜单
    U->>CM: 选择目标知识分组
    CM->>NM: saveAsKnowledge(id, toGroupId)
    NM->>NM: isKnowledge = true
    NM->>NM: groupId = 用户选择的分组ID
    NM->>DB: saveNotes()
```

**优点：**
- 用户体验一致：与现有「移动到分组」子菜单交互方式相同
- 实现简单：仅需将 Button 替换为 Menu，新增一个 NoteManager 方法
- 无额外弹窗，操作流畅

**缺点：**
- 如果知识分组较多，子菜单可能较长（但一般分组不会太多）

### 方案二：保留按钮 + 额外弹出面板

```mermaid
sequenceDiagram

    participant CM as 右键菜单
    participant PP as 弹出面板
    participant NM as NoteManager
    participant DB as 数据持久化

    U->>CM: 右键笔记
    U->>CM: 点击「保存为知识」
    CM->>PP: 弹出知识分组选择面板
    U->>PP: 选择目标分组
    PP->>NM: saveAsKnowledge(id, toGroupId)
    NM->>NM: isKnowledge = true
    NM->>NM: groupId = 用户选择的分组ID
```

**优点：**
- 可以在面板中提供更丰富的交互（如搜索、预览）

**缺点：**
- 实现复杂：需要额外的弹窗管理逻辑
- 操作步骤变多，体验不如子菜单流畅
- 与现有右键菜单风格不一致

## 测试用例

1. **右键普通笔记 → 查看「保存为知识」子菜单**
   - 预期：悬停后展开子菜单，列出所有知识分组（智库、以及用户自建的知识分组）

2. **选择某个知识分组**
   - 预期：笔记从当前普通分组消失，出现在选中的知识分组中，且笔记被标记为知识

3. **右键已是知识的笔记**
   - 预期：菜单显示「从知识库移除」按钮（非子菜单），点击后笔记回到默认普通分组

4. **仅有默认知识分组时保存为知识**
   - 预期：子菜单中只有「智库」一项，选择后笔记移入智库

## 任务总结与结论

采用方案一，将右键菜单中的「保存为知识」按钮改为 Menu 子菜单，展开后列出所有知识分组供用户选择。

```mermaid
sequenceDiagram
    participant U as 用户
    participant CM as 右键菜单
    participant NM as NoteManager
    participant DB as 数据持久化

    U->>CM: 右键普通笔记
    U->>CM: 悬停「保存为知识」
    CM->>NM: getSortedGroups(isKnowledgeGroup: true)
    NM-->>CM: 返回知识分组列表
    CM->>CM: 展开知识分组子菜单
    U->>CM: 选择目标知识分组
    CM->>NM: saveAsKnowledge(id, toGroupId)
    NM->>NM: isKnowledge = true, groupId = 选中分组
    NM->>DB: saveNotes()
```

修改两个文件：
- Note.swift：新增 `saveAsKnowledge(id:toGroupId:)` 方法，设置 isKnowledge 并移动到指定分组
- NoteListView.swift：将「保存为知识」Button 替换为 Menu 子菜单，非知识笔记展开分组选择，已是知识的笔记显示「从知识库移除」按钮
