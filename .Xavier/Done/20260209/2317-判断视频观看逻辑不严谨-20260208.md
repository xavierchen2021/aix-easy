# 判断视频观看逻辑不严谨

## 概述
重新设计视频/休息判断逻辑，基于键鼠活动和音频输出的组合。

## 最终判断逻辑

```mermaid
flowchart TD
    Start([计时检查]) --> CheckInput{键鼠有活动?}
    CheckInput -->|是| Working[工作状态
计时累加]
    CheckInput -->|否| CheckAudio{有音频输出?}
    CheckAudio -->|是| VideoMode[视频/音乐模式
计时暂停]
    CheckAudio -->|否| IdleMode[空闲模式
走现有空闲逻辑]
    
    Working --> Update[更新UI]
    VideoMode --> Update
    IdleMode --> Update
    
    subgraph 规则说明
    R1[规则1: 键鼠活动 = 最高优先级
一定是工作]
    R2[规则2: 无键鼠 + 有音频 = 看视频
直接暂停计时]
    R3[规则3: 无键鼠 + 无音频 = 离开
按空闲阈值判断是否休息]
    end
```

## 任务总结与结论

### 修改内容

#### 1. VideoDetector.swift（完整重写）
**修改位置:** [/Volumes/Cache/X/Sources/Model/VideoDetector.swift](vscode://file/Volumes/Cache/X/Sources/Model/VideoDetector.swift:1)

- 移除了所有视频/全屏检测逻辑
- 使用 CoreAudio API 实现纯音频输出检测
- 新增 `isAudioPlaying()` 方法，检测系统默认输出设备是否有音频流

#### 2. SmartReminderManager.swift（逻辑重构）
**修改位置:** [/Volumes/Cache/X/Sources/Model/SmartReminderManager.swift](vscode://file/Volumes/Cache/X/Sources/Model/SmartReminderManager.swift:275)

- 移除了 `isInVideoMode` 状态变量
- 移除了 `extendedWorkDuration` 变量及相关逻辑
- 移除了 `pausedWorkDuration` 变量
- 重写 `handleTimerTick()` 方法，实现新的判断逻辑：
  - 有键鼠活动 → 计时累加
  - 无键鼠 + 有音频 → 暂停计时（视频/音乐模式）
  - 无键鼠 + 无音频 → 走空闲逻辑

### 最终逻辑流程

```mermaid
flowchart TD
    Start([计时检查]) --> CheckInput{键鼠有活动?}
    CheckInput -->|是| Working[工作状态<br/>计时累加]
    CheckInput -->|否| CheckAudio{有音频输出?}
    CheckAudio -->|是| VideoMode[视频/音乐模式<br/>计时暂停<br/>显示: 🎵 检测到媒体播放]
    CheckAudio -->|否| IdleMode[空闲模式<br/>空闲时间>阈值?]
    IdleMode -->|是| RestMode[休息模式<br/>显示休息窗口]
    IdleMode -->|否| PauseOnly[仅暂停<br/>不计入休息]
    
    Working --> Update[更新UI]
    VideoMode --> Update
    RestMode --> Update
    PauseOnly --> Update
```

### 改进效果

1. **逻辑更清晰**: 只有3条规则，无歧义
2. **覆盖更全面**: 不依赖应用类型，支持所有播放器
3. **代码更简洁**: 移除了大量复杂的状态管理
4. **更准确**: 键鼠活动优先级最高，避免误判
