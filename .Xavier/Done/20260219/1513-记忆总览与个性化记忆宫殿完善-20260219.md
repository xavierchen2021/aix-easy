# 记忆总览与个性化记忆宫殿完善

## 概述
基于测试反馈完善记忆功能体验：
1. 新增记忆总览专用窗口，集中查看记忆条目。
2. 记忆总览样式调整为更易读布局（复习时间左上、原文置顶、原文容器化展示）。
3. 在偏好设置增加“固定复习时间”配置入口。
4. 增加“房间布局描述”输入，用于个性化记忆宫殿提示生成。

## 当前实现
```mermaid
flowchart TD
  A[菜单栏入口] --> B[记忆总览窗口]
  B --> C[展示全部记忆条目]
  C --> D[显示复习时间/原文/记忆宫殿内容]
  E[偏好设置] --> F[复习触发方式]
  F --> G[固定时间模式]
  F --> H[语义触发模式]
  E --> I[房间布局描述]
  I --> J[AI生成个性化记忆宫殿提示]
```

## 测试用例
1. 菜单栏可打开“记忆总览”窗口。
2. 列表中可查看完整原文与记忆宫殿内容。
3. 原文区域为紫色容器，右上角“原文”标签仅在 hover 显示。
4. 设置中可切换“固定时间/语义触发”并保存。
5. 设置中填写房间布局后，新生成的记忆宫殿提示应体现房间锚点；为空则走通用方式。

## 方案
### 推荐🚀 方案A：在现有架构上做增量体验优化
```mermaid
flowchart LR
  A[MemoryManager配置扩展] --> B[设置页新增配置项]
  B --> C[AI记忆宫殿生成加入房间上下文]
  C --> D[记忆总览窗口与样式优化]
```

优点
- 改动集中、风险低。
- 与现有阶段1/阶段2逻辑兼容。

缺点
- 总览窗口仍为单页列表，后续可继续增加筛选分组能力。
