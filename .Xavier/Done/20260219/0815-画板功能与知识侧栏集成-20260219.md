# 画板功能与知识侧栏集成

## 概述
在 X 项目新增画板功能：
- 左侧为可任意尺寸的画板区域；
- 右侧为知识笔记侧栏（上方分组、下方知识笔记列表），尽量复用现有知识笔记体系；
- 可将右侧知识笔记添加到画板；
- 可在画板中链接不同笔记节点。
- 画板窗口入口放到菜单栏菜单项中。

## 测试用例
1. 入口与窗口
  - 在菜单栏点击“画板”菜单项。
  - 重复点击菜单项，验证打开/关闭或聚焦行为。
   - 期望：窗口可稳定开关并贴近悬浮球定位。

2. 右侧知识侧栏
   - 切换知识分组，观察列表变更。
   - 期望：只展示当前分组知识笔记，复用现有分组与数据源。

3. 添加节点
   - 从右侧点击“添加到画板”。
   - 期望：左侧画板出现对应笔记节点，节点可拖拽。

4. 链接节点
   - 先选择“开始连线”节点，再选择目标节点。
   - 期望：节点间出现连线，可重复建立多个连接。

5. 画板尺寸
   - 调整画板宽高（任意大小范围）。
   - 期望：画板可滚动查看并继续操作节点。

## 方案
### 方案A：在现有 NoteWindow 内新增画板模式
```mermaid
flowchart LR
  A[复用NoteWindow] --> B[新增ViewMode.board]
  B --> C[在NoteListView混入画板UI]
```

优点
- 入口改动小。

缺点
- `NoteListView` 职责膨胀，维护成本高。
- 画板交互与笔记列表交互耦合严重。

### 推荐🚀 方案B：新增独立 CanvasBoardWindow + CanvasBoardView，入口挂到菜单栏
```mermaid
flowchart TD
  A[新增菜单项 画板] --> B[AppDelegate分发到CanvasBoardWindow]
  B --> C[CanvasBoardView]
  C --> D[左侧可滚动画板+节点连线]
  C --> E[右侧知识分组+知识列表]
  E --> F[添加笔记到画板节点]
```

优点
- 画板与笔记列表解耦，结构清晰。
- 右侧可复用现有 `NoteManager` 数据与分组规则。
- 便于后续扩展（持久化、更多连线样式）。

缺点
- 需要新增窗口与视图文件。
