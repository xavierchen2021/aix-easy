# 剪切板历史透明度改为不透明

## 概述

修改剪切板历史窗口的背景透明度，将目前半透明的蓝色背景（`Color.blue.opacity(0.7)`）改为完全不透明（`Color.blue.opacity(1.0)` 或 `Color.blue`）。

## 当前实现

在 [NoteListView.swift](vscode://file/Volumes/Cache/X/Sources/View/NoteListView.swift:910) 中的 `ClipboardPreviewView` 结构体：

```
.background(
    RoundedRectangle(cornerRadius: 20)
        .fill(Color.blue.opacity(0.7))  ← 当前透明度为 0.7
        .overlay(
            RoundedRectangle(cornerRadius: 20)
                .stroke(Color.white.opacity(0.3), lineWidth: 1)
        )
)
```

## 问题

剪切板历史窗口的背景为半透明，会显示背后的内容，导致文字可读性不够好。

## 方案

### 推荐方案 📌

修改 `ClipboardPreviewView` 中的背景颜色透明度：

**修改位置**：
- [NoteListView.swift](vscode://file/Volumes/Cache/X/Sources/View/NoteListView.swift:914) - 第 914 行

**具体修改**：
将：
```swift
.fill(Color.blue.opacity(0.7))
```

改为：
```swift
.fill(Color.blue)
// 或者
.fill(Color.blue.opacity(1.0))
```
