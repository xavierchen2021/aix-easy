# 修改悬浮球添加方式

## 概述
当前悬浮球的添加方式需要通过设置界面配置数量，现在需要修改为在状态栏右键菜单上直接添加悬浮球，无需在设置中配置数量。

## 流程图
```mermaid
graph TD
    A[用户点击状态栏菜单] --> B[选择添加悬浮球选项]
    B --> C[创建新的悬浮球窗口]
    C --> D[更新配置和界面显示]
    D --> E[刷新状态栏菜单]
```

## 方案
1. 在状态栏右键菜单中添加"添加悬浮球"选项
2. 当用户点击该选项时，直接创建一个新的悬浮球窗口
3. 更新配置管理器中的按钮数量
4. 刷新所有窗口显示
5. 更新状态栏菜单状态
