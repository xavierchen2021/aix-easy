# 菜单栏图标宽度随时间变化

## 概述
菜单栏显示的倒计时文本（如 "09:59 / 44:59"）宽度随数字变化而跳动，因为使用了普通系统字体（比例字体），不同数字（如 1 和 0）宽度不同。

## 当前实现

```mermaid
flowchart LR
    A[SmartReminderManager] -->|通知| B[StatusBarTimerView]
    B -->|updateWorkTimer| C[timerLabel]
    C -->|"09:59 / 44:59"| D[NSStatusItem variableLength]
    D -->|宽度变化| E[❌ 菜单栏跳动]
```

当前使用 `NSFont.systemFont(ofSize:weight:)` — 比例字体，数字宽度不一致。

## 方案

### 🚀推荐方案：使用等宽数字字体

将 `NSFont.systemFont` 改为 `NSFont.monospacedDigitSystemFont`，确保所有数字字符宽度一致。

**优点**：
- 一行代码改动，最小侵入
- 数字宽度完全一致，消除跳动
- 非数字字符仍保持正常比例显示

**缺点**：无

**修改位置**：
[StatusBarTimerView.swift](vscode://file/Volumes/Cache/X/Sources/View/StatusBarTimerView.swift:40) — setupUI 中的 font 定义
[StatusBarTimerView.swift](vscode://file/Volumes/Cache/X/Sources/View/StatusBarTimerView.swift:112) — makeAttributedString 中的 font 定义

## 测试用例
1. 观察菜单栏倒计时从 "09:59" 过渡到 "10:00" → 宽度不应跳变
2. 观察 "00:01 / 44:59" 到 "00:02 / 44:58" → 宽度稳定

## 任务总结与结论
将 StatusBarTimerView 中的字体从 `NSFont.systemFont` 改为 `NSFont.monospacedDigitSystemFont`，确保数字字符等宽，消除菜单栏宽度跳动。

