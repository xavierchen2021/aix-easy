# 优化全局快捷键设置交互

## 概述
优化偏好设置中全局快捷键的编辑交互，默认禁止编辑，点击修改按钮后才能编辑，保存后恢复禁用状态。

## 当前实现

当前快捷键设置 UI：
- 输入框始终可编辑
- 右侧显示"保存"按钮
- 下方显示当前快捷键和"重置"按钮

## 方案

### 🚀 推荐方案：添加编辑状态管理

为每个快捷键输入框添加编辑状态，控制输入框的启用/禁用和按钮文字切换。

#### 修改后代码
在 HotkeyConfigurationSection 中添加编辑状态：

```swift
struct HotkeyConfigurationSection: View {
    @ObservedObject private var configManager = FloatingButtonConfigManager.shared
    @State private var hotkeyInput = ""
    @State private var colorPickerHotkeyInput = ""
    @State private var isEditingHotkey = false  // 新增
    @State private var isEditingColorPickerHotkey = false  // 新增
    private let defaultHotkey = "Control+Shift+Cmd+O"
    private let defaultColorPickerHotkey = "Cmd+Shift+P"

    var body: some View {
        VStack(alignment: .leading, spacing: 16) {
            // 显示/隐藏悬浮球快捷键
            SettingsRow(...) {
                HStack(spacing: 8) {
                    TextField("例如：Control+Shift+Cmd+O", text: $hotkeyInput)
                        .disabled(!isEditingHotkey)  // 根据编辑状态禁用
                        .textFieldStyle(RoundedBorderTextFieldStyle())
                        .frame(width: 180)
                        .font(.system(.body, design: .monospaced))
                        .onSubmit {
                            if !hotkeyInput.isEmpty && isEditingHotkey {
                                configManager.updateToggleAIXHotkey(hotkeyInput)
                                isEditingHotkey = false
                            }
                        }

                    Button(action: {
                        if isEditingHotkey {
                            // 保存模式
                            if !hotkeyInput.isEmpty {
                                configManager.updateToggleAIXHotkey(hotkeyInput)
                                isEditingHotkey = false
                            }
                        } else {
                            // 修改模式
                            isEditingHotkey = true
                        }
                    }) {
                        Text(isEditingHotkey ? "保存" : "修改")  // 按钮文字切换
                            .font(.caption)
                            .padding(.horizontal, 12)
                            .padding(.vertical, 6)
                            .background(
                                isEditingHotkey ? 
                                Color.accentColor.opacity(0.2) : 
                                Color.gray.opacity(0.2)
                            )
                            .cornerRadius(4)
                    }
                    .buttonStyle(PlainButtonStyle())
                }
            }

            // 取色器快捷键（同样的逻辑）
            SettingsRow(...) {
                HStack(spacing: 8) {
                    TextField("例如：Cmd+Shift+P", text: $colorPickerHotkeyInput)
                        .disabled(!isEditingColorPickerHotkey)  // 根据编辑状态禁用
                        .textFieldStyle(RoundedBorderTextFieldStyle())
                        .frame(width: 180)
                        .font(.system(.body, design: .monospaced))
                        .onSubmit {
                            if !colorPickerHotkeyInput.isEmpty && isEditingColorPickerHotkey {
                                configManager.updateColorPickerHotkey(colorPickerHotkeyInput)
                                isEditingColorPickerHotkey = false
                            }
                        }

                    Button(action: {
                        if isEditingColorPickerHotkey {
                            // 保存模式
                            if !colorPickerHotkeyInput.isEmpty {
                                configManager.updateColorPickerHotkey(colorPickerHotkeyInput)
                                isEditingColorPickerHotkey = false
                            }
                        } else {
                            // 修改模式
                            isEditingColorPickerHotkey = true
                        }
                    }) {
                        Text(isEditingColorPickerHotkey ? "保存" : "修改")  // 按钮文字切换
                            .font(.caption)
                            .padding(.horizontal, 12)
                            .padding(.vertical, 6)
                            .background(
                                isEditingColorPickerHotkey ? 
                                Color.accentColor.opacity(0.2) : 
                                Color.gray.opacity(0.2)
                            )
                            .cornerRadius(4)
                    }
                    .buttonStyle(PlainButtonStyle())
                }
            }
            
            // 其余代码保持不变...
        }
        .onAppear {
            hotkeyInput = configManager.config.toggleAIXHotkey
            colorPickerHotkeyInput = configManager.config.colorPickerHotkey
            isEditingHotkey = false  // 默认禁用编辑
            isEditingColorPickerHotkey = false  // 默认禁用编辑
        }
    }
}
```

#### 优点
- 防止误操作，提升用户体验
- 清晰的编辑/保存状态切换
- 视觉上明确区分编辑模式和查看模式
- 保存后自动退出编辑模式

#### 缺点
- 需要多点一次按钮才能编辑

10. 关闭并重新打开设置，验证状态正确
