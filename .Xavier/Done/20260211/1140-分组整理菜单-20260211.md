# 分组整理菜单

## 概述
在悬浮球右键菜单中新增“整理分组”入口：当悬浮球属于分组时显示该菜单项，点击后仅整理该分组内悬浮球，按均匀间隔排列，不移动到屏幕右半边。

## 当前实现
```mermaid
flowchart TD
    A[菜单栏: 整理悬浮球] --> B[全量排列所有悬浮球]
    C[分组变更通知] --> D[按分组排列成员]
```

## 方案
### 方案一：复用分组排列逻辑，右键菜单触发（推荐方案✅）
```mermaid
flowchart TD
    A[右键悬浮球] --> B{是否有分组}
    B -- 是 --> C[显示“整理分组”]
    C --> D[触发分组排列通知]
    D --> E[仅整理分组成员]
```
优点：
- 复用现有分组排列实现，改动范围小
- 满足“仅分组内整理、不移至右半屏”要求

缺点：
- 依赖分组布局设置，需确保间距一致

- [AppDelegate.swift](vscode://file/Volumes/Cache/X/Sources/App/AppDelegate.swift:1015)

### 方案二：新增独立分组整理方法（不复用通知）
```mermaid
flowchart TD
    A[右键悬浮球] --> B[直接调用分组整理方法]
    B --> C[仅整理分组成员]
```
优点：
- 流程更直观，不依赖通知

缺点：
- 需新增方法并维护两套整理入口

## 测试用例
1. 将多个悬浮球加入同一分组，右键任意分组成员，确认出现“整理分组”。
2. 点击“整理分组”，仅分组内悬浮球按均匀间隔排列，位置不移动到屏幕右半边。
3. 单成员分组不显示“整理分组”或点击无效果。

## 任务总结与结论
已在悬浮球右键菜单加入“整理分组”，并复用分组排列逻辑，按统一间距在原位置整理分组成员，避免移动到屏幕右半边。

```mermaid
flowchart TD
    A[右键分组成员] --> B[显示整理分组]
    B --> C[触发分组排列通知]
    C --> D[统一间距排列分组成员]
```
