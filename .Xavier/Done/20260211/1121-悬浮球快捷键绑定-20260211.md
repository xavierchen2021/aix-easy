# 悬浮球快捷键绑定

## 概述
为悬浮球新增“执行快捷键”能力：用户可为每个悬浮球绑定一个快捷键，点击悬浮球时触发该快捷键的全局执行。

## 当前实现
```mermaid
flowchart TD
    A[悬浮球点击] --> B[读取按钮动作]
    B --> C{动作类型}
    C --> D[打开笔记/剪切板/常用文件等]
    C --> E[控制窗口/提醒/颜色列表/插件]
    C --> F[无操作]
```

## 方案
### 方案一：新增“执行快捷键”动作 + 右键菜单绑定（推荐方案✅）
```mermaid
flowchart TD
    A[右键菜单选择动作] --> B[设置为执行快捷键]
    B --> C[绑定快捷键字符串]
    D[点击悬浮球] --> E[读取绑定快捷键]
    E --> F[解析组合键并发送全局按键事件]
```
优点：
- 贴合现有动作体系，操作入口清晰
- 每个悬浮球独立绑定，灵活
- 与当前快捷键格式保持一致

缺点：
- 需要新增热键解析与事件发送的公共工具

### 方案二：复用全局隐藏快捷键（不新增绑定字段）
```mermaid
flowchart TD
    A[点击悬浮球] --> B[读取全局隐藏快捷键]
    B --> C[发送固定快捷键]
```
优点：
- 实现最简单，不新增配置字段

缺点：
- 无法做到每个悬浮球独立绑定
- 与需求“可绑定”不完全一致

## 测试用例
1. 将某悬浮球动作设置为“执行快捷键”，绑定如 Cmd+Shift+Y，点击悬浮球，确认系统收到该快捷键。
2. 未绑定快捷键时点击悬浮球，确认有提示或无操作。
3. 删除悬浮球后，确认快捷键绑定数据随索引迁移。
4. 多个悬浮球分别绑定不同快捷键，点击时互不影响。
