# 音频检测改为一次性10秒窗口

## 概述
将音频检测从"持续循环检测"改为"一次性10秒窗口"：空闲6秒后监听10秒，10秒内有5秒以上有响度则认定看视频，否则停止监听，本轮空闲不再重试，直到下次键鼠活动后再次空闲达6秒才重新监听。

## 当前实现

```mermaid
sequenceDiagram
    participant T as 定时器
    participant S as 状态机
    participant A as 音频监控(SCStream)

    Note over T: idleTime > 6
    T->>A: 启动音频监控
    
    loop 每5秒一轮，持续重试
        A-->>S: 统计loudCount
        alt loudCount >= 3
            S->>S: 进入视频模式
        else loudCount < 3
            Note over S: 重置计时器，保持监控运行
            Note over S: ⚠️ 立即开始下一轮5秒检测（无限循环）
        end
    end
```

## 测试用例
1. 停止键鼠6秒，应开始音频监听（日志出现"音频捕获启动"）
2. 若有视频音频：10秒内应进入视频模式（日志出现"进入视频模式"）
3. 若无视频音频：10秒后应看到"音频捕获停止"，此后不再监听
4. 恢复键鼠活动再次停止6秒后，应重新开始监听

## 方案

### 🚀 推荐方案：一次性10秒检测窗口

```mermaid
sequenceDiagram
    participant T as 定时器
    participant S as 状态机
    participant A as 音频监控(SCStream)

    Note over T: idleTime > 6 且未检测过
    T->>A: 启动音频监控
    
    rect rgb(200, 255, 200)
    loop 10秒检测窗口（每秒）
        A-->>S: hasAudioSamples() && isOutputLoud()
        Note over S: audioLoudCount++（有响度时）
    end
    end

    alt audioLoudCount >= 5
        S->>S: ✅ 进入视频模式，停止监控
    else audioLoudCount < 5
        S->>A: ❌ 停止监控，标记本轮已检测
        Note over S: 不再重试，等待下次键鼠活动
    end
    
    Note over T: 键鼠恢复 → resetAudioCheck()
    Note over T: 清除"已检测"标记，下次空闲可再检测
```

**优点**：
- 精确控制监听时长，避免无限循环浪费资源
- 10秒窗口更充裕，SCStream启动延迟不再是问题
- 5/10秒阈值比3/5秒更宽容，减少误判

**缺点**：
- 需新增 `audioCheckCompleted` 标记属性

将音频检测从"持续循环5秒窗口"改为"一次性10秒窗口"：

```mermaid
sequenceDiagram
    participant T as 定时器
    participant S as 状态机
    participant A as 音频监控

    Note over T: idleTime > 6 且 !audioCheckCompleted

    Note over T: audioCheckCompleted 重置为 false
```
