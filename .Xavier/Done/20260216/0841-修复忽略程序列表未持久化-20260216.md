# 修复忽略程序列表未持久化

## 概述
自动隐藏功能的忽略程序列表（excludedApps）配置后无法持久化。重启应用后列表为空。

## 当前实现

```mermaid
sequenceDiagram
    participant I as init()
    participant L as loadConfig()
    participant D as didSet
    participant S as saveConfig()
    participant DB as SQLite

    I->>L: 调用 loadConfig()
    L->>DB: 读取 isEnabled = "1"
    L->>L: self.isEnabled = true
    
    rect rgb(255, 200, 200)
    Note over D: ⚠️ didSet 触发
    D->>S: saveConfig()
    Note over S: excludedApps = []（默认空值）
    S->>DB: 写入 excludedApps = ""
    Note over DB: 原有数据被覆盖！
    end

    L->>DB: 读取 excludedApps = ""
    Note over L: 空字符串，跳过赋值
    Note over L: 结果：excludedApps 丢失
```

## 测试用例
1. 打开偏好设置 → 自动隐藏 → 添加忽略程序
2. 退出并重启应用
3. **预期**：忽略程序列表保持不变

## 方案

### 🚀 推荐方案：加载期间抑制 saveConfig

```mermaid
sequenceDiagram
    participant I as init()
    participant L as loadConfig()
    participant D as didSet
    participant S as saveConfig()
    participant DB as SQLite

    I->>L: 调用 loadConfig()
    Note over L: isLoading = true
    L->>DB: 读取 isEnabled
    L->>L: self.isEnabled = true
    D->>S: saveConfig()
    Note over S: isLoading = true → 跳过保存
    L->>DB: 读取 timeout
    L->>DB: 读取 excludedApps
    L->>L: self.excludedApps = 已保存值
    Note over L: isLoading = false
    Note over L: ✅ 所有属性恢复完毕
```

**优点**：改动最小（3行），不改变 didSet 逻辑
**缺点**：无

**修改位置**：

## 任务总结与结论

在 AutoHideManager.swift 中添加 `isLoading` 标志，`loadConfig()` 期间设为 true 抑制 `saveConfig()` 调用，修复了加载时 didSet 提前触发导致已存数据被空值覆盖的问题。

```mermaid

    L->>L: self.timeout = DB值
    L--xS: saveConfig() → isLoading → 跳过
    L->>L: self.excludedApps = DB值
    L--xS: saveConfig() → isLoading → 跳过
    Note over L: isLoading = false
    Note over L: ✅ 所有属性正确恢复
```
