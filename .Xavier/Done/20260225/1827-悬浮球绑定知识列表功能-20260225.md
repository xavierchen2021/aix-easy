# 悬浮球绑定知识列表功能

## 概述
在悬浮球右键菜单的可绑定功能中添加「知识列表」选项，用户绑定后点击悬浮球可直接打开知识列表视图（NoteListView 的 `.knowledge` 模式）。

## 当前实现

```mermaid
graph TD
    FloatBtn[悬浮球右键菜单] --> BindMenu[绑定功能菜单]
    BindMenu --> None[无]
    BindMenu --> OpenNote[打开笔记]
    BindMenu --> Completed[已完成]
    BindMenu --> Clipboard[剪切板]
    BindMenu --> Favorites[常用文件]
    BindMenu --> AIList[AI列表]
    BindMenu --> ToggleWin[控制窗口]
    BindMenu --> ColorList[颜色列表]
    BindMenu --> Hotkey[执行快捷键]
    BindMenu --> Plugin[插件]
    
    OpenNote -->|点击| NoteWin[打开笔记窗口 mode:.all]
    Clipboard -->|点击| ClipWin[打开笔记窗口 mode:.clipboard]
    Completed -->|点击| CompWin[打开笔记窗口 mode:.completed]
    Favorites -->|点击| FavWin[打开笔记窗口 mode:.favorites]
    AIList -->|点击| AIWin[打开笔记窗口 mode:.ai]
    
    style BindMenu fill:#f96,stroke:#333
```

`NoteListView.ViewMode` 已有 `.knowledge` 枚举值，但 `ButtonAction` 中缺少对应的 `showKnowledgeList` case。

## 测试用例
1. 右键任意悬浮球 → 在绑定功能列表中应出现「知识列表」选项
2. 选择绑定「知识列表」后，单击悬浮球
3. 应弹出/关闭笔记窗口，且窗口显示的是知识列表视图（与顶部工具栏切换到知识库效果一致）
4. 再次点击悬浮球应关闭(toggle)知识列表窗口

## 方案

### 🚀 推荐方案：新增 ButtonAction.showKnowledgeList

```mermaid

    KnowledgeList -->|点击| KnowWin[打开笔记窗口 mode:.knowledge]
```

- 改动极小，与现有架构完全一致

**缺点：**
- 无
