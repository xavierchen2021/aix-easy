# 活动记录窗口输入聚焦修复

## 概述
活动记录弹窗（输入"这一小时你做了什么？"）存在以下三个问题：
1. 打开后 TextEditor 无法直接输入，需要手动点击才能聚焦
2. 弹窗应显示在屏幕**左下角**（参考复习提示的右下角实现）
3. 记录时的时间戳应为**前一个小时**，而非点击"记录"时的当前时间

## 当前实现

```mermaid
sequenceDiagram
    participant Timer as 定时器
    participant AW as ActivityInputWindow.show()
    participant Win as NSWindow
    participant TV as NSTextView(TextEditor底层)

    Timer->>AW: 触发弹窗
    AW->>Win: makeKeyAndOrderFront(nil)
    AW->>Win: NSApp.activate(ignoringOtherApps:true)
    Note over TV: SwiftUI TextEditor 尚未完成布局\nNSTextView 还未被渲染为 firstResponder
    Note over Win: 窗口已弹出但输入框无焦点
```

**问题根因**：`makeKeyAndOrderFront` 执行时，SwiftUI 的 `TextEditor` 尚未完成内部 `NSTextView` 的创建，窗口虽然是 keyWindow，但没有 firstResponder 指向 NSTextView。

## 测试用例
1. 等待活动记录计时器触发（或在设置中将间隔设短）
2. 弹窗出现后，**不点击任何位置**，直接敲键盘输入文字
3. 输入应直接进入文本框

## 🚀 推荐方案

### 方案一：综合修复（三个问题一并解决）

```mermaid
sequenceDiagram
    participant AW as ActivityInputWindow.show()
    participant Win as NSWindow
    participant TV as NSTextView
    participant AT as ActivityTracker.recordActivity()

    AW->>Win: 计算左下角坐标（visible.minX+20, visible.minY+20）
    AW->>Win: setFrameOrigin + makeKeyAndOrderFront
    AW->>AW: asyncAfter(0.1s) findTextView → makeFirstResponder
    Note over Win: 窗口在左下角显示，输入框自动聚焦

    AT->>AT: let recordTime = Date().addingTimeInterval(-3600)
    Note over AT: 时间戳为前一小时，格式化显示
```

**代码修改位置：**
- [ActivityInputWindow.swift](vscode://file/Volumes/Cache/X/Sources/View/ActivityInputWindow.swift:154) — 窗口定位改为左下角
- [ActivityTracker.swift](vscode://file/Volumes/Cache/X/Sources/Model/ActivityTracker.swift:97) — 时间戳改为 Date().addingTimeInterval(-3600)
