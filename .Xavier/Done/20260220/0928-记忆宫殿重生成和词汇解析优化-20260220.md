# 记忆宫殿重生成和词汇解析优化

## 概述
两个子任务：
1. **记忆宫殿助记重新生成**：用户修改偏好设置中的房间布局后，已有的记忆宫殿助记应该能够重新生成。所有展示记忆宫殿助记的地方都应有"重新生成"按钮
2. **词汇解析字段优化**：当前 `grammar` 字段实际返回的是词性而非句法解读；`sentence` 字段缺少中文翻译和句法分析

## 当前实现

### 子任务1：记忆宫殿助记


**问题**：
- 语言学习窗口词汇详情和学习页展示 `memoryPalace` 但无重新生成按钮
- 记忆总览窗口展示 `palaceCue` 但无重新生成按钮
- 用户修改房间布局后，已有助记不会自动更新

## 方案

### 🚀 推荐方案

#### 子任务1：添加重新生成按钮

```mermaid
sequenceDiagram
    participant U as 用户
    participant LW as 语言学习窗口
    participant LM as LanguageLearningManager
    participant AI as AIService
    participant MOW as 记忆总览窗口
    participant MM as MemoryManager

    U->>LW: 点击记忆宫殿助记旁的「🔄」按钮
    LW->>LM: regenerateMemoryPalace(for: itemId)
    LM->>AI: generateMemoryPalaceCue(content, roomLayoutContext)
    AI-->>LM: 新的 memoryPalace
    LM->>LW: 更新 item.memoryPalace

    U->>MOW: 点击记忆宫殿旁的「🔄」按钮
    MOW->>MM: regeneratePalaceCue(for: entryId)
    MM->>AI: generateMemoryPalaceCue(content, roomLayoutContext)
    AI-->>MM: 新的 palaceCue
    MM->>MOW: 更新 entry.palaceCue
```

**优点**：
- 用户可随时在需要的地方主动刷新助记
- 复用已有的 `generateMemoryPalaceCue` AI 接口
- 自动读取最新的 `palaceLayoutContext` 房间布局

**缺点**：
- 每次重新生成需调用一次 AI

#### 子任务2：优化词汇字段

```mermaid
flowchart TD
    A[AI prompt 修改] --> B{"grammar → 改名为 partOfSpeech"}
    B -->|"返回词性"| C["UI 标题：「词性」"]

    D -->|"返回句子中文翻译"| E["UI：「所在句子」下方显示翻译"]

    style B fill:#9f9,stroke:#0a0

```

**修改要点**：
- `LearningVocabularyItem` 新增 `sentenceTranslation` 和 `sentenceAnalysis` 字段
- 原 `grammar` 字段语义改为「词性」
- AI prompt 中增加 `sentenceTranslation`、`sentenceAnalysis` 字段要求
- `LearningWordPayload` 同步增加字段
- UI 展示顺序调整：词义 → 词根 → 词性 → 所在句子 → 句子翻译 → 句法解读 → 记忆宫殿助记

**优点**：
- 字段语义清晰准确
- 学习信息更完整

**缺点**：
- prompt 返回字段增多，可能影响 AI 响应速度

## 任务总结与结论

完成了以下改进，修改了 6 个文件：

```mermaid
flowchart TD
    A[AI prompt 优化] --> B[grammar → 词性]
    A --> C[新增 sentenceTranslation]
    A --> D[新增 sentenceAnalysis]
    A --> E[sentence 明确为英文原文]

    F[记忆宫殿重生成] --> G[词汇详情 🔄 按钮]
    F --> H[学习页 🔄 按钮]
    F --> I[记忆总览 🔄 按钮]

    J[批次持久化] --> K[VocabularyBatch 结构]
    J --> L[历史批次选择器]
    J --> M[批次删除管理]

    N[UI 增强] --> O[文字可框选复制]
    N --> P[学习页 上一个 按钮]
```

1. **字段优化**：grammar→词性，新增句子翻译和句法解读，AI prompt 逐字段说明
2. **记忆宫殿重生成**：三处展示位置均添加重新生成按钮，读取最新房间布局
3. **批次持久化**：解析记录以时间批次形式保存，支持切换和删除
4. **UI 增强**：所有文字支持框选复制，学习页增加上一个按钮
