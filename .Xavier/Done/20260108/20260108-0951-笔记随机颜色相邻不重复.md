# 笔记随机颜色相邻不重复

## 概述
当前笔记系统有5种随机颜色，在创建新笔记时只排除了第一个笔记的颜色，导致相邻笔记可能出现相同颜色的情况。需要修改随机颜色生成逻辑，确保新笔记的颜色与前面N个笔记的颜色都不相同（N为颜色总数）。

## 流程图
```mermaid
sequenceDiagram
    participant User as 用户
    participant NoteManager as NoteManager
    participant Note as Note
    participant DB as 数据库
    
    User->>NoteManager: 添加新笔记
    NoteManager->>Note: 获取前面N个笔记的颜色
    Note->>Note: 计算可用的颜色列表
    Note->>Note: 从可用颜色中随机选择
    Note-->>NoteManager: 返回随机颜色
    NoteManager->>DB: 保存笔记
    DB-->>NoteManager: 保存成功
    NoteManager-->>User: 笔记创建成功
```

## 方案

### 当前问题
1. `Note.randomColorHex(excluding:)` 方法只接受一个排除颜色参数
2. `NoteManager.addNote()` 和 `addNewEmptyNote()` 只排除了第一个笔记的颜色
3. 导致相邻笔记可能出现相同颜色

### 解决方案
修改 `Note.randomColorHex()` 方法，支持排除多个颜色：
1. 将参数从 `excluding: String?` 改为 `excluding: [String]?`
2. 从颜色列表中过滤掉所有需要排除的颜色
3. 从剩余的颜色中随机选择

### 推荐方案
修改 `Note.swift` 中的 `randomColorHex` 方法，并更新 `NoteManager` 中调用该方法的地方。
