# 大窗口编辑颜色与笔记一致

## 概述
修改笔记大窗口编辑界面的背景颜色，使其与笔记卡片颜色一致（使用 `note.colorHex`），同时将大窗口层级设置在笔记列表之上。

## 当前实现

```mermaid
graph TD
    A[LargeNoteView] --> B[背景: VisualEffectView hudWindow]
    C[LargeNoteWindow] --> D[level: .floating]
    E[NoteWindow 笔记列表] --> F[level: .floating]
    Note1[问题: 大窗口与笔记列表同级]
    Note2[问题: 大窗口背景为系统毛玻璃，不随笔记颜色]
```

## 方案

### 🚀推荐方案 方案一：传递颜色到大窗口 + 提升窗口层级

1. 将 `note.colorHex` 传递到 `LargeNoteView`，替换背景为笔记颜色渐变
2. 将 `LargeNoteWindow` 的 `level` 设置为 `floating + 1`

```mermaid
graph TD
    A[LargeNoteView] --> B[背景: note.colorHex 渐变色]
    C[LargeNoteWindow] --> D[level: floating + 1]
    E[NoteWindow] --> F[level: floating]
    D -->|高于| F
```

**优点：**
- 视觉一致性
- 简洁直接

**缺点：**
- 无

## 测试用例

1. 右键不同颜色的笔记，选择大窗口编辑，确认背景色与笔记卡片一致
2. 打开大窗口时，确认在笔记列表之上
3. 大窗口中编辑文字清晰可见
