# 笔记右键移到最顶端

## 概述
在笔记 item 的右键菜单中添加"移到最顶端"选项，将选中的笔记排到当前列表的最前面。

## 当前实现
```mermaid
sequenceDiagram
    participant U as 用户
    participant NLV as NoteListView
    participant NM as NoteManager
    participant NS as NoteStore
    participant DB as SQLite

    U->>NLV: 查看笔记列表
    NLV->>NM: notes(分组过滤)
    NM->>NS: getAllNotes()
    NS->>DB: SELECT ... ORDER BY createdAt DESC
    DB-->>NS: 按创建时间倒序
    NS-->>NM: [Note]
    NM-->>NLV: 过滤后的笔记列表
    Note right of DB: 排序完全依赖 createdAt<br/>无独立排序字段
```

当前排序机制：
- Note 表没有独立的排序字段
- 所有排序通过 `ORDER BY createdAt DESC` 实现
- NoteGroup 有 `sortOrder` 字段但 Note 没有

## 方案

### 🚀推荐方案：新增 pinnedAt 字段

```mermaid
sequenceDiagram
    participant U as 用户
    participant NLV as NoteListView
    participant NM as NoteManager
    participant NS as NoteStore
    participant DB as SQLite

    U->>NLV: 右键笔记 → 移到最顶端
    NLV->>NM: moveToTop(id)
    NM->>NS: updatePinnedAt(id, Date())
    NS->>DB: UPDATE Note SET pinnedAt = ? WHERE id = ?
    DB-->>NS: ✅
    NM-->>NLV: 刷新列表
    NLV->>NM: notes
    NM->>NS: getAllNotes()
    NS->>DB: SELECT ... ORDER BY pinnedAt DESC NULLS LAST, createdAt DESC
    Note right of DB: pinnedAt 不为空的排在前面<br/>pinnedAt 内部按时间倒序<br/>普通笔记按 createdAt 倒序
```

**优点**：
- 保留原始创建时间
- 支持多个置顶笔记（按置顶时间排序）
- 可扩展：将来可加"取消置顶"
- 数据库迁移简单（ALTER TABLE ADD COLUMN）

**缺点**：
- 需要数据库迁移
- 新增一个可空字段

### 方案二：修改 createdAt 时间戳

右键"移到最顶端"时将 `createdAt` 更新为当前时间。

**优点**：
- 无需数据库迁移
- 实现极简

**缺点**：
- 丢失原始创建时间（UI 中会显示错误的创建日期）
- 不可逆

## 测试用例
1. 在任意笔记分组中创建多条笔记
2. 右键最底部的笔记，点击"移到最顶端"
3. 验证该笔记出现在列表第一位
4. 再右键另一条笔记"移到最顶端"，验证它排在之前置顶的笔记之上
5. 验证 AI 聊天列表中的笔记也支持"移到最顶端"
6. 验证知识库笔记也支持"移到最顶端"
7. 重启应用后验证置顶状态持久化

## 任务总结与结论
通过新增 `pinnedAt` 可空时间字段实现笔记置顶功能。数据库排序改为 `CASE WHEN pinnedAt IS NOT NULL THEN 0 ELSE 1 END, pinnedAt DESC, createdAt DESC`，确保置顶笔记始终在前且按置顶时间倒序。

```mermaid
sequenceDiagram
    participant U as 用户
    participant NLV as NoteListView
    participant NM as NoteManager
    participant NS as NoteStore
    participant DB as SQLite

    U->>NLV: 右键笔记 → 移到最顶端
    NLV->>NM: moveToTop(id)
    NM->>NM: notes[index].pinnedAt = Date()
    NM->>NS: insertNote(note)
    NS->>DB: UPDATE pinnedAt = now
    NM->>NM: loadData() 重新排序
    NS->>DB: SELECT ... ORDER BY pinnedAt优先, createdAt DESC
    DB-->>NLV: 置顶笔记排在最前
```

修改文件：Note.swift（模型+NoteManager）、NoteStore.swift（迁移+SQL）、NoteListView.swift（右键菜单）
