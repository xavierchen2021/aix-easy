# 悬浮球组贴边隐藏

## 测试用例

### 用例一：开关配置（分组绑定）

```mermaid
flowchart TD
    A[右键悬浮球打开个性化设置] --> B{该球是否属于某分组?}
    B -- 否 --> C[分组设置下方的贴边隐藏开关呈置灰不可点状态]
    B -- 是 --> D[贴边隐藏开关显示当前分组的开启状态]
    D --> E[点击开关切换]
    E --> F[配置立即保存, 无需点击应用按钮]
    F --> G[右键组内另一个球打开个性化设置]
    G --> H[开关状态与刚才修改的一致, 证明整组共享]
    H --> I[重启应用后再查看, 状态保持]
```

```mermaid
    C --> D{整组是否贴近左/右/顶部边缘?}

    H -- 是 --> I[列表窗口与球组同步动画滑出, 保持相对位置]
    H -- 否 --> J[结束, 等待唤回]
    I --> J
```

## 方案

### 推荐方案概述

在现有悬浮球分组体系上，新增一个集中式的「贴边隐藏管理器」（单例，风格对齐现有自动隐藏管理器），统一承载贴边隐藏的完整状态机；分组模型上新增持久化的「贴边隐藏」开关，随现有配置体系保存并向后兼容。

核心思路分四部分：

1. **配置层**：分组配置新增「贴边隐藏」布尔字段，默认关闭，随现有 JSON 配置持久化，解码时对旧数据自动补默认值。配置入口放在悬浮球个性化设置面板的分组设置区域（排列方式）下方，未分组的球开关置灰，改动即时保存并对整组生效。

2. **触发与滑出**：接入现有分组拖拽结束事件。真实拖拽（区别于纯点击）松手后，若整组贴近屏幕左、右或顶部边缘（判定距离约 20px），管理器先将整组吸附对齐到边缘，再以两段式动画将整组（含依附的列表窗口）平移出屏幕。顶部滑出位置避让菜单栏，完全不可见。

3. **唤回与滑回**：管理器在存在隐藏分组期间启用全局鼠标移动监听（用于屏幕边缘热区检测唤回）与全局/本地鼠标点击监听。鼠标进入热区则整组滑出至贴边位置；鼠标离开窗口（hover离开）不再触发隐藏，仅在用户点击窗口外部的内容时整组（含列表）滑回屏幕外隐藏。滑出显示期间按下球即解除该组的贴边隐藏状态，之后的拖拽与松手按普通分组逻辑处理。

4. **位置与状态持久化**：窗口坐标照常走现有按球保存的通道（滑出动画结束后自然保存屏幕外坐标）；管理器按分组另存「隐藏中」状态与贴边方向。因滑出前已吸附对齐，唤回位置可由方向直接推导，无需双份记录隐藏前坐标。应用启动时按状态标志把隐藏组的窗口直接放在屏幕外位置；关闭开关、解散分组、删除分组、删除成员球等生命周期事件发生时，若该组正处于隐藏状态则先滑回屏幕内再清理状态，杜绝窗口遗留在屏幕外找不回。监听屏幕参数变化，分辨率变更时对隐藏组重新计算屏幕外坐标作为兜底。

### 优缺点

优点：
- 状态机集中在管理器内，悬浮球窗口、应用代理、列表窗口只被动响应指令，避免逻辑散落多文件
- 「先吸附再滑出」使唤回位置可由方向推导，不引入第二份坐标存储，避免位置不一致
- 全局鼠标监听仅在存在隐藏分组时启用并做事件节流，空闲时零开销
- 配置向后兼容，旧版本数据可正常解码升级
- 生命周期兜底完整（关开关/解散/删组/删球/换屏幕），不会出现球丢失在屏幕外

缺点与风险：
- 全局鼠标移动监听在高频移动时持续触发，虽已节流仍有轻微常驻开销（仅在隐藏期间存在，可接受）
- 顶部隐藏的唤回需要鼠标越过菜单栏进入屏幕最顶部条带，交互灵敏度略低于左右两侧
- 列表窗口较高时同步滑出的位移较大，动画视觉略明显
- 屏幕外窗口在极少数系统场景（如分辨率热切换）下坐标可能失效，需依赖屏幕变化兜底逻辑

### Mermaid 时序图

#### 主流程：拖拽贴边隐藏与热区唤回

```mermaid
sequenceDiagram
    participant U as 用户
    participant V as 悬浮球视图/窗口
    participant M as 贴边隐藏管理器
    participant D as 应用代理
    participant N as 笔记列表窗口
    participant S as 配置存储

    Note over U,S: 前置: 分组已开启贴边隐藏开关
    U->>V: 按下球并拖动整组到屏幕边缘
    V->>D: 拖拽过程(同组成员联动移动, 现有逻辑不变)
    U->>V: 松开鼠标(真实拖拽)
    V->>D: 拖拽结束事件
    D->>S: 保存组内各球位置
    D->>M: 通知拖拽结束(携带被拖拽球)
    M->>M: 判定整组是否贴近左/右/顶部边缘(约20px)
    alt 贴近边缘且分组开启开关
        M->>M: 整组吸附对齐到屏幕边缘
        M->>V: 动画平移整组出屏幕(记录贴边方向与所属屏幕)
        M->>N: 若列表打开且依附球在组内, 同步动画平移出屏幕
        M->>S: 持久化该组"隐藏中"状态与方向
        M->>M: 启动边缘热区鼠标监听(节流)
    else 未贴近或未开启开关
        M-->>D: 不处理, 球组留在原地
    end

    Note over U,M: 一段时间后, 唤回
    U->>M: 鼠标移入对应屏幕边缘热区
    M->>V: 整组动画滑出至贴边位置显示
    M->>N: 列表同步滑回依附位置
    U->>V: 悬停球组或操作列表(点击球正常触发功能)
    U->>M: 鼠标离开 热区∪球组∪列表 区域
    M->>V: 整组动画滑回屏幕外
    M->>N: 列表同步滑回屏幕外
    Note over M: 隐藏状态保留, 可反复唤回

    U->>V: 唤回状态下按下球并拖离边缘
    V->>M: 拖拽开始
    M->>M: 解除该组贴边隐藏状态(清除持久化标志)
    M->>M: 停止对应热区监听(若无其他隐藏组)
    Note over U,V: 之后按普通分组拖拽逻辑处理
```

#### 生命周期流程：开关、分组变更、启动恢复

```mermaid
sequenceDiagram
    participant U as 用户
    participant P as 个性化设置面板
    participant M as 贴边隐藏管理器
    participant C as 分组配置管理
    participant V as 悬浮球窗口
    participant S as 配置存储

    Note over U,S: 开关配置
    U->>P: 右键球打开个性化设置
    P->>C: 读取该球所在分组
    alt 球未分组
        P-->>U: 贴边隐藏开关置灰不可用
    else 属于分组
        P-->>U: 开关显示分组当前状态
        U->>P: 切换开关
        P->>C: 更新分组贴边隐藏字段并保存
        C-->>P: 即时生效, 整组共享
    end

    Note over U,M: 隐藏状态下关闭开关
    U->>P: 关闭某隐藏分组的贴边隐藏
    P->>C: 保存开关为关闭
    C->>M: 通知分组配置变化
    M->>V: 整组带动画滑回屏幕内贴边位置
    M->>S: 清除该组隐藏状态标志
    M->>M: 停止热区监听(若无其他隐藏组)

    Note over C,M: 分组解散/删除/成员删除
    C->>M: 分组生命周期变化通知
    M->>M: 该组正处于隐藏状态?
    M->>V: 是则先滑回屏幕内再清理状态
    M->>S: 清除该组隐藏状态标志

    Note over U,S: 应用重启恢复
    S-->>M: 读取各分组隐藏状态与方向
    S-->>V: 各球加载已保存坐标(隐藏组为屏幕外坐标)
    M->>M: 隐藏组保持屏幕外, 重新启用热区监听
    M->>V: 屏幕参数变化时重新计算屏幕外坐标(兜底)
```
