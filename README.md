## 一、悬浮球系统

### 1.1 基础功能
| # | 功能 | 说明 |
|---|------|------|
| 1 | 多悬浮球支持 | 同时创建 1–10 个独立悬浮球，每个可单独配置 |
| 2 | 悬浮球大小调节 | 每个悬浮球可单独设置大小（30–150px） |
| 3 | 悬浮球拖拽移动 | 拖拽悬浮球在屏幕任意位置自由移动 |
| 4 | 屏幕边缘吸附 | 靠近屏幕边缘 20px 内自动吸附对齐 |
| 5 | 位置持久化 | 记住每个悬浮球的位置，重启后恢复 |
| 6 | 始终置顶 | 所有悬浮球窗口始终浮于其他窗口之上 |
| 7 | 全空间可见 | 悬浮球在所有桌面空间和全屏应用中可见 |
| 8 | 添加新悬浮球 | 通过状态栏菜单「添加悬浮球」增加新球 |
| 9 | 删除悬浮球 | 悬浮球数量大于 1 时可删除指定悬浮球 |
| 10 | 单独隐藏悬浮球 | 右键菜单可隐藏单个悬浮球 |
| 11 | 一键显示/隐藏全部 | 状态栏菜单一键切换所有悬浮球可见性 |
| 12 | 排列悬浮球 | 将所有悬浮球重新排列到屏幕右下角 |

### 1.2 外观定制
| # | 功能 | 说明 |
|---|------|------|
| 13 | 颜色主题 | 提供 7 种渐变配色方案：海蓝、翡翠、落日、玫瑰、极光、暗夜、月光 |
| 14 | 每球独立颜色 | 每个悬浮球可覆盖全局颜色，使用独立配色 |
| 15 | 悬浮球形状 | 支持圆形和胶囊两种形状，可全局或逐球设置 |
| 16 | 显示模式 | 支持「仅图标」和「仅文字」两种显示模式 |
| 17 | 自定义图标 | 每个悬浮球可设置不同的 SF Symbols 图标 |
| 18 | SF Symbols 图标选择器 | 按 14 个类别（常用/通讯/天气/对象/箭头/设备/人物/自然/交通/运动/文字/健康等）浏览选择图标 |
| 19 | 渐变色填充 | 悬浮球使用径向渐变色填充 |

### 1.3 动画效果
| # | 功能 | 说明 |
|---|------|------|
| 20 | 鼠标悬停放大 | 鼠标悬停时悬浮球微微放大（1.1x）并显示发光 |
| 21 | 点击弹性动画 | 点击时播放弹性缩放（0.95→1.0）动画 |
| 22 | 波纹扩散动画 | 点击时从球心向外扩散水波纹特效 |
| 23 | 光芒爆发动画 | 点击时显示短暂的光芒爆发效果 |
| 24 | 发光层效果 | 悬浮球周围的柔和外发光效果 |
| 25 | 边缘描边特效 | 鼠标悬停时显示与球形状一致的边缘光效 |

### 1.4 呼吸效果与透明度
| # | 功能 | 说明 |
|---|------|------|
| 26 | 呼吸灯动画 | 可开关的周期性呼吸动画，模拟「呼吸」的明暗变化 |
| 27 | 呼吸速度调节 | 呼吸动画速度可调（0.2x–3.0x） |
| 28 | 发光浓度调节 | 悬浮球外发光强度可调（0%–100%） |
| 29 | 笔记透明度 | 笔记内容区域透明度可调（10%–100%） |
| 30 | 工具栏透明度 | 笔记顶部工具栏透明度可调（10%–100%） |
| 31 | 分组透明度 | 分组区域透明度可调（10%–100%） |
| 32 | 呼吸效果透明度 | 呼吸动画本身的透明度可调（0%–100%） |

### 1.5 悬浮球动作绑定
| # | 功能 | 说明 |
|---|------|------|
| 33 | 动作类型 | 每个球可绑定 7 种点击动作：无操作/打开笔记/显示已完成/显示剪切板/显示常用文件/控制窗口/插件 |
| 34 | 个性化设置面板 | 右键每个悬浮球可打开专属的个性化设置窗口 |

### 1.6 悬浮球分组
| # | 功能 | 说明 |
|---|------|------|
| 35 | 创建分组 | 多个悬浮球可归入同一个命名分组 |
| 36 | 分组拖拽联动 | 拖拽分组内任一悬浮球时，同组其他球跟随移动 |
| 37 | 分组排列方式 | 支持水平和垂直两种排列方向 |
| 38 | 分组成员管理 | 可添加/移除分组成员，或将球移至其他分组 |
| 39 | 分组自动排列 | 应用设置后自动排列分组中所有球的位置 |

## 二、笔记系统

### 2.1 笔记操作
| # | 功能 | 说明 |
|---|------|------|
| 40 | 快速新建笔记 | 在笔记输入框中输入内容按 Enter 即可创建 |
| 41 | Shift+Enter 换行 | 输入框中 Shift+Enter 插入换行而非提交 |
| 42 | 笔记编辑 | 支持行内编辑和弹出大窗口编辑两种模式 |
| 43 | 大窗口编辑器 | 独立浮动窗口编辑笔记，支持更大输入区域 |
| 44 | 笔记删除（软删除） | 删除笔记移入回收站而非永久删除 |
| 45 | 标记完成 | 笔记可标记为已完成状态 |
| 46 | 保存为知识 | 普通笔记可转存为知识库条目，支持选择目标知识分组 |
| 47 | 笔记分组间移动 | 笔记可在不同分组之间移动 |
| 48 | 随机颜色标识 | 每条笔记自动分配随机颜色 |
| 49 | 自动编辑空笔记 | 新创建的空笔记自动进入编辑模式 |
| 50 | 复制笔记内容 | 右键菜单可复制笔记内容到剪切板 |

### 2.2 笔记视图
| # | 功能 | 说明 |
|---|------|------|
| 51 | 多视图模式 | 笔记列表支持 6 种视图：全部/已完成/剪切板/知识库/常用文件/回收站 |
| 52 | 搜索筛选 | 在当前视图中按关键词搜索笔记 |
| 53 | 悬停操作按钮 | 鼠标悬停笔记行时显示编辑/完成/删除等快捷按钮 |
| 54 | 右键上下文菜单 | 右键笔记弹出菜单，包含编辑/完成/知识库/复制/移动/删除等操作 |
| 55 | Toast 通知 | 操作完成后显示短暂的成功提示 |

### 2.3 回收站
| # | 功能 | 说明 |
|---|------|------|
| 56 | 查看已删除笔记 | 在回收站视图中查看所有已删除笔记 |
| 57 | 恢复笔记 | 从回收站恢复笔记到原分组 |
| 58 | 彻底删除 | 从回收站永久删除单条笔记 |
| 59 | 清空回收站 | 一键永久清除回收站中所有笔记 |

### 2.4 笔记窗口
| # | 功能 | 说明 |
|---|------|------|
| 60 | 浮动面板 | 笔记窗口为 NSPanel 类型，支持非激活面板交互 |
| 61 | 窗口高度可调 | 设置中可配置笔记弹出窗口的高度 |
| 62 | 搜索时自动加宽 | 打开搜索框时窗口宽度自动增加 |
| 63 | 毛玻璃背景 | 使用 NSVisualEffectView 实现毛玻璃材质效果 |

## 七、智能休息提醒

### 7.1 活动检测

| 100 | 三状态判断逻辑 | 活跃操作→工作中；无操作+有声音→看视频/听音乐暂停；无操作+无声→空闲 |

| 105 | 辅助功能权限检查 | 自动检测是否已获得辅助功能权限 |
| 106 | 屏幕锁定/休眠检测 | 监听 screenIsLocked/screensDidSleep 通知 |
