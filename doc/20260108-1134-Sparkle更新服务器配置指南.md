# Sparkle 更新服务器配置指南

## 概述

本文档详细说明如何使用 GitHub Pages 配置 Sparkle 更新服务器，实现 macOS 应用的自动更新功能。

## 配置步骤

### 步骤 1: 创建 GitHub 仓库

创建一个新的 GitHub 仓库用于托管更新文件，仓库名可以是：
- `aix-updates`
- `aix-appcast`

### 步骤 2: 生成 Ed25519 密钥对

```bash
# 下载 Sparkle 工具
cd ~/Downloads
git clone https://github.com/sparkle-project/Sparkle.git
cd Sparkle/bin

# 生成密钥对
./generate_keys -p ~/Desktop/aix_private_key.pem
```

这会生成：
- **私钥**: `~/Desktop/aix_private_key.pem`（必须保密！）
- **公钥**: 终端输出的 Base64 字符串，格式类似 `RW5v8lq9Y7F0eJ2k3m4n5o6p7q8r9s0t1u2v3w4x5y6z7A8B9C0D1E2F3G4H5I6J7K8L9M0N`

### 步骤 3: 创建 appcast.xml 文件

在本地创建 `appcast.xml` 文件：

```xml
<?xml version="1.0" encoding="utf-8"?>
<rss version="2.0" xmlns:sparkle="http://www.andymatuschak.org/xml-namespaces/sparkle" xmlns:dc="http://purl.org/dc/elements/1.1/">
  <channel>
    <title>AIX App Updates</title>
    <link>https://yourusername.github.io/aix-updates/appcast.xml</link>
    <description>Most recent updates for AIX</description>
    <language>en</language>
    
    <item>
      <title>Version 1.0.0</title>
      <link>https://github.com/yourusername/your-repo/releases/tag/1.0.0</link>
      <sparkle:version>1.0.0</sparkle:version>
      <sparkle:shortVersionString>1.0.0</sparkle:shortVersionString>
      <sparkle:minimumSystemVersion>10.15</sparkle:minimumSystemVersion>
      <description><![CDATA[
        <h2>版本 1.0.0</h2>
        <ul>
          <li>初始版本发布</li>
          <li>添加自动更新功能</li>
        </ul>
      ]]></description>
      <pubDate>Wed, 08 Jan 2026 12:00:00 +0000</pubDate>
      <enclosure 
        url="https://github.com/yourusername/your-repo/releases/download/1.0.0/AIX-1.0.0.zip" 
        sparkle:edSignature="your-signature-here" 
        sparkle:version="1.0.0"
        type="application/octet-stream" 
        length="12345678" />
    </item>
  </channel>
</rss>
```

### 步骤 4: 准备更新包

```bash
# 1. 构建你的应用
cd /Volumes/Cache/X
swift build --configuration release

# 2. 创建 .app 包（如果还没有）
# 通常使用 Xcode 或 swift build 会生成可执行文件
# 你需要手动创建 .app 包结构

# 3. 创建 zip 文件
# 假设你的 .app 在 build/release/AIX.app
cd build/release
zip -r AIX-1.0.0.zip AIX.app

# 4. 使用私钥签名 zip 文件
~/Downloads/Sparkle/bin/sign_update ~/Desktop/aix_private_key.pem AIX-1.0.0.zip
```

这会输出一个签名，类似：
```
aB3dE5fG7hI9jK1lM3nO5pQ7rS9tU1vW3xY5zA7bC9dE1fG3hI5jK7lM9nO1pQ3
```

将这个签名填入 appcast.xml 的 `sparkle:edSignature` 属性。

### 步骤 5: 上传更新包到 GitHub Releases

1. 在 GitHub 上创建一个新的 Release：
   - Tag: `1.0.0`
   - Title: `Version 1.0.0`
   - Description: 发布说明

2. 上传 `AIX-1.0.0.zip` 文件到 Release

3. 获取下载 URL：
   ```
   https://github.com/yourusername/your-repo/releases/download/1.0.0/AIX-1.0.0.zip
   ```

### 步骤 6: 启用 GitHub Pages

1. 进入你的 GitHub 仓库 `aix-updates`
2. 点击 **Settings** → **Pages**
3. 在 **Source** 下选择：
   - **Branch**: `main` 或 `gh-pages`
   - **Folder**: `/ (root)`
4. 点击 **Save**

等待几分钟后，GitHub Pages 会生成一个 URL：
```
https://yourusername.github.io/aix-updates/
```

### 步骤 7: 上传 appcast.xml 到 GitHub Pages

有两种方法：

**方法 1: 直接推送到 main 分支**

```bash
cd ~/Desktop
mkdir aix-updates
cd aix-updates
git init

# 复制 appcast.xml 到这个目录
cp /path/to/appcast.xml .

git add appcast.xml
git commit -m "Add appcast.xml"
git branch -M main
git remote add origin https://github.com/yourusername/aix-updates.git
git push -u origin main
```

**方法 2: 使用 gh-pages 分支**

```bash
cd ~/Desktop
mkdir aix-updates
cd aix-updates
git init

# 复制 appcast.xml 到这个目录
cp /path/to/appcast.xml .

git add appcast.xml
git commit -m "Add appcast.xml"
git branch -M gh-pages
git remote add origin https://github.com/yourusername/aix-updates.git
git push -u origin gh-pages
```

### 步骤 8: 配置 Info.plist

更新你的 Info.plist：

```xml
<key>SUFeedURL</key>
<string>https://yourusername.github.io/aix-updates/appcast.xml</string>
<key>SUPublicEDKey</key>
<string>RW5v8lq9Y7F0eJ2k3m4n5o6p7q8r9s0t1u2v3w4x5y6z7A8B9C0D1E2F3G4H5I6J7K8L9M0N</string>
<key>SUEnableAutomaticChecks</key>
<true/>
<key>SUAutomaticallyUpdate</key>
<false/>
<key>SUScheduledCheckInterval</key>
<integer>86400</integer>
```

将 `SUPublicEDKey` 替换为你生成的真实公钥。

### 步骤 9: 完整示例

假设你的 GitHub 用户名是 `xavierdev`，项目名是 `aix`：

**GitHub 仓库结构**：
```
aix-updates/
└── appcast.xml
```

**GitHub Releases**：
```
https://github.com/xavierdev/aix/releases/download/1.0.0/AIX-1.0.0.zip
```

**GitHub Pages URL**：
```
https://xavierdev.github.io/aix-updates/appcast.xml
```

**Info.plist 配置**：
```xml
<key>SUFeedURL</key>
<string>https://xavierdev.github.io/aix-updates/appcast.xml</string>
<key>SUPublicEDKey</key>
<string>你的真实公钥</string>
```

### 步骤 10: 测试更新

1. 修改 Info.plist 中的版本号为 `0.9.0`（比 appcast.xml 中的版本低）
2. 运行应用
3. 点击"检查更新"
4. 应该会提示有新版本 `1.0.0` 可用

## 注意事项

⚠️ **重要**：
1. **私钥必须保密**：不要将 `aix_private_key.pem` 上传到 GitHub
2. **公钥必须公开**：将公钥添加到 Info.plist
3. **HTTPS 要求**：Sparkle 要求更新服务器使用 HTTPS（GitHub Pages 默认支持）
4. **版本号格式**：确保 appcast.xml 和 Info.plist 中的版本号格式一致
5. **文件大小**：在 appcast.xml 的 `enclosure` 标签中添加 `length` 属性，值为 zip 文件的字节数

## 自动化脚本（可选）

创建一个自动化脚本来简化发布流程：

```bash
#!/bin/bash
# release.sh

VERSION=$1
PRIVATE_KEY=~/Desktop/aix_private_key.pem
GITHUB_USER=xavierdev
REPO=aix

if [ -z "$VERSION" ]; then
    echo "Usage: ./release.sh <version>"
    exit 1
fi

echo "Building AIX version $VERSION..."

# 构建应用
cd /Volumes/Cache/X
swift build --configuration release

# 创建 zip 文件
cd build/release
zip -r AIX-$VERSION.zip AIX.app

# 获取文件大小
FILE_SIZE=$(stat -f%z AIX-$VERSION.zip)

# 签名
SIGNATURE=$(~/Downloads/Sparkle/bin/sign_update $PRIVATE_KEY AIX-$VERSION.zip)

echo "Signature: $SIGNATURE"
echo "File size: $FILE_SIZE"

# 提示上传到 GitHub Releases
echo "Please upload AIX-$VERSION.zip to GitHub Releases"
echo "Then update appcast.xml with:"
echo "  - url: https://github.com/$GITHUB_USER/$REPO/releases/download/$VERSION/AIX-$VERSION.zip"
echo "  - signature: $SIGNATURE"
echo "  - length: $FILE_SIZE"
```

使用方法：
```bash
chmod +x release.sh
./release.sh 1.0.0
```
