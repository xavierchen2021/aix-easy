> 本文档事无巨细地列举 AIX 软件的所有功能点，按模块分类整理。

## 一、悬浮球系统

### 1.1 基础功能
| # | 功能 | 说明 |
|---|------|------|
| 1 | 多悬浮球支持 | 同时创建 1–10 个独立悬浮球，每个可单独配置 |
| 2 | 悬浮球大小调节 | 每个悬浮球可单独设置大小（30–150px） |
| 3 | 悬浮球拖拽移动 | 拖拽悬浮球在屏幕任意位置自由移动 |
| 4 | 屏幕边缘吸附 | 靠近屏幕边缘 20px 内自动吸附对齐 |
| 5 | 位置持久化 | 记住每个悬浮球的位置，重启后恢复 |
| 6 | 始终置顶 | 所有悬浮球窗口始终浮于其他窗口之上 |
| 7 | 全空间可见 | 悬浮球在所有桌面空间和全屏应用中可见 |
| 8 | 添加新悬浮球 | 通过状态栏菜单「添加悬浮球」增加新球 |
| 9 | 删除悬浮球 | 悬浮球数量大于 1 时可删除指定悬浮球 |
| 10 | 单独隐藏悬浮球 | 右键菜单可隐藏单个悬浮球 |
| 11 | 一键显示/隐藏全部 | 状态栏菜单一键切换所有悬浮球可见性 |
| 12 | 排列悬浮球 | 将所有悬浮球重新排列到屏幕右下角 |

### 1.2 外观定制
| # | 功能 | 说明 |
|---|------|------|
| 13 | 颜色主题 | 提供 7 种渐变配色方案：海蓝、翡翠、落日、玫瑰、极光、暗夜、月光 |
| 14 | 每球独立颜色 | 每个悬浮球可覆盖全局颜色，使用独立配色 |
| 15 | 悬浮球形状 | 支持圆形和胶囊两种形状，可全局或逐球设置 |
| 16 | 显示模式 | 支持「仅图标」和「仅文字」两种显示模式 |
| 17 | 自定义图标 | 每个悬浮球可设置不同的 SF Symbols 图标 |
| 18 | SF Symbols 图标选择器 | 按 14 个类别（常用/通讯/天气/对象/箭头/设备/人物/自然/交通/运动/文字/健康等）浏览选择图标 |
| 19 | 渐变色填充 | 悬浮球使用径向渐变色填充 |

|---|------|------|
