# 智能提醒系统时序图文档

## 概述
本文档详细描述了 AIX 应用中智能提醒系统的完整工作流程，包括启动、工作计时、空闲检测、音频/视频模式、休息检测、用户交互、系统休眠唤醒等各个环节的时序关系。

## 系统组件

### 核心组件
- **SmartReminderManager**: 智能提醒管理器，负责整个提醒流程的协调
- **InputMonitor**: 输入监听器，监测键盘鼠标活动和系统锁定状态
- **AudioActivityMonitor**: 音频活动监测器，检测系统音频输出判断用户是否在看视频/听音乐
- **StatusBarTimerView**: 菜单栏计时显示视图
- **ReminderOverlayWindow**: 休息提醒蒙版窗口

### 配置组件
- **SmartReminderConfig**: 智能提醒配置
  - workDuration: 工作时长（默认45分钟）
  - restDuration: 休息时长（默认5分钟）
  - idleThreshold: 空闲阈值（默认60秒）
  - restRecognitionTime: 休息认定时间（默认270秒，即4分30秒）

### 1. 系统启动流程

```mermaid
sequenceDiagram

    participant App as 应用主程序
    participant SRM as SmartReminderManager
    participant IM as InputMonitor
    participant SBT as StatusBarTimerView

    SRM->>SRM: 注册 .systemDidWake 通知

    SRM->>SRM: setupInputMonitor() 设置回调
    SRM->>SRM: setupReminderOverlay() 设置蒙版回调
    
    User->>App: 开启智能提醒
    App->>SRM: start()
    
    SRM->>SRM: restoreState() 恢复之前状态
    SRM->>SRM: lastActivityCheckTime = Date()
    SRM->>IM: startMonitoring() 开始监听
    SRM->>SRM: startTimer() 启动1秒定时器
    SRM->>SRM: updateStatusBarTimer() 立即更新UI
    SRM->>SBT: 发送 SmartReminderEnabled 通知
    
    Note over SBT: 菜单栏显示初始状态

```

### 2. 正常工作计时流程（handleTimerTick 主循环）

```mermaid
sequenceDiagram
    participant User as 用户
    participant IM as InputMonitor
    participant SRM as SmartReminderManager
    participant SBT as StatusBarTimerView
    
    loop 每秒 handleTimerTick()
        SRM->>IM: timeSinceLastActivity()
        IM-->>SRM: idleDuration
        
        alt 蒙版正在显示
            alt 蒙版状态=workComplete 且用户无操作 >= idleThreshold
                SRM->>SRM: isWorkPaused = true
                SRM->>SRM: startRestTimer(.workComplete)
                Note over SRM: 自动进入休息倒计时
            end
            SRM->>SRM: updateStatusBarTimer()
        else 用户活跃（idleDuration < 1.0）
            SRM->>SRM: 退出视频模式（如果在视频模式）
            SRM->>SRM: 从暂停恢复（如果在暂停）
            SRM->>SRM: activeDuration += timeSinceLastCheck
            SRM->>SRM: idleStartTime = nil, 重置音频检测
        else 用户不活跃
            alt idleStartTime 为 nil
                SRM->>SRM: idleStartTime = now
                Note over SRM: 开始空闲计时
            end
            alt 视频模式中
                Note over SRM: 冻结空闲计时，不累加工作时间
            else 非视频模式
                SRM->>SRM: evaluateAudioCheckWindow(now)
                alt idleDuration >= idleThreshold 且 !isWorkPaused
                    SRM->>SRM: isWorkPaused = true
                    SRM->>SRM: pausedActiveDuration = activeDuration
                    SRM->>SRM: startRestTimer(.idleDetected)
                else idleDuration < idleThreshold 且 !isWorkPaused
                    SRM->>SRM: activeDuration += timeSinceLastCheck
                    Note over SRM: 短暂空闲仍计为工作
                end
            end
        end
        
        SRM->>SRM: checkAndShowReminder()
        SRM->>SRM: updateStatusBarTimer()
        SRM->>SBT: 发送 SmartReminderStateChanged 通知
    end
```

### 3. 音频检测与视频模式

```mermaid
sequenceDiagram
    participant IM as InputMonitor
    participant SRM as SmartReminderManager
    participant AM as AudioActivityMonitor
    
    Note over SRM: 用户无键鼠操作
    SRM->>SRM: idleStartTime = now
    
    Note over SRM: 空闲持续 15 秒...
    
    SRM->>SRM: evaluateAudioCheckWindow(now)
    SRM->>AM: startMonitoring()
    Note over AM: 开始监测系统音频输出
    
    loop 5 秒检测窗口
        SRM->>AM: hasAudioSamples()? isOutputLoud()?
        
        alt 音频持续输出（全部 5 秒都有声音）
            Note over SRM: audioWindowAllActive 保持 true
        else 音频中断或无采样
            SRM->>SRM: audioWindowAllActive = false
            SRM->>AM: stopMonitoring()
            Note over SRM: 非视频模式，正常空闲检测
        end
    end
    
    alt audioWindowAllActive == true（5秒全有音频）
        SRM->>SRM: enterVideoMode()
        SRM->>SRM: isVideoMode = true
        SRM->>SRM: frozenIdleTime = min(5.0, 实际空闲)
        Note over SRM: 进入视频模式：暂停工作计时，冻结空闲时间
    else audioWindowAllActive == false
        Note over SRM: 不进入视频模式，继续正常空闲流程
    end
    
    Note over SRM: 视频模式中...用户恢复键鼠操作
    IM->>SRM: 检测到活动
    SRM->>SRM: exitVideoMode()
    SRM->>SRM: isVideoMode = false, idleStartTime = nil
    Note over SRM: 恢复正常工作计时
```

### 4. 达到工作时长触发提醒流程

```mermaid
sequenceDiagram
    participant User as 用户
    participant SRM as SmartReminderManager
    participant IM as InputMonitor
    participant Overlay as ReminderOverlayWindow
    
    SRM->>SRM: checkAndShowReminder()
    Note over SRM: activeDuration >= workDuration
    
    SRM->>SRM: showReminder()
    
    Note over SRM: 禁用活动检测回调
    SRM->>SRM: savedActivityCallback = onActivityDetected
    SRM->>IM: onActivityDetected = {}
    
    SRM->>Overlay: overlayState = .workComplete
    SRM->>Overlay: message = config.reminderMessage
    SRM->>Overlay: show()
    
    SRM->>SRM: playSound(config.soundName)
    SRM->>SRM: hasPlayedReminderSound = true
    
    Note over SRM,Overlay: 等待用户响应...

    alt 用户无操作 >= idleThreshold（handleTimerTick检测）
        SRM->>SRM: isWorkPaused = true
        SRM->>SRM: restStartTime = now
        SRM->>SRM: startRestTimer(.workComplete)
        Note over SRM: 自动进入休息倒计时（状态2）
    else 用户点击"稍后休息"
        User->>Overlay: 点击按钮
        Overlay->>SRM: onContinue → handleReminderContinue()
        SRM->>SRM: 恢复活动检测回调
        SRM->>Overlay: close()
        SRM->>SRM: resetAllState()
        Note over SRM: 重置所有状态，重新开始工作计时
    end
```

```mermaid
    SRM->>Overlay: message = "感知到您已离开，自动进入休息"
```

### 7. 用户从空闲/休息中回来（键鼠活动检测）

```mermaid
sequenceDiagram
    participant User as 用户
    participant IM as InputMonitor
    participant SRM as SmartReminderManager
    participant Overlay as ReminderOverlayWindow
    
    Note over SRM: isWorkPaused=true, 蒙版可能未显示
    Note over SRM: 用户通过键鼠活动被 handleTimerTick 检测到
    
    SRM->>SRM: handleUserReturned(now)
    SRM->>IM: refreshActivity()
    SRM->>SRM: idleStartTime = nil
    
    SRM->>SRM: 计算 restDuration = now - restStartTime
    
    alt restDuration >= restRecognitionTime
        SRM->>SRM: activeDuration = 0
        Note over SRM: 充分休息，重置工作倒计时
        alt 蒙版正在显示
            SRM->>Overlay: close()
        end
    else restDuration < restRecognitionTime
        SRM->>SRM: activeDuration = pausedActiveDuration
        Note over SRM: 短暂离开，恢复暂停的倒计时
    end
    
    SRM->>SRM: isWorkPaused = false
    SRM->>SRM: 停止 restTimer + restCountdownTimer
    SRM->>SRM: hasPlayedReminderSound = false
```

### 8. 系统锁屏/解锁处理

```mermaid
sequenceDiagram
    participant System as 系统
    participant IM as InputMonitor
    participant SRM as SmartReminderManager
    participant Overlay as ReminderOverlayWindow
    
    alt 锁屏 / 屏幕休眠
        System->>IM: screensDidSleep / screenIsLocked
        IM->>IM: isLocked = true
        IM->>SRM: onLockStateChanged(true) [Task异步]
        SRM->>SRM: idleStartTime = now（如果还没设置）
    end
    
    alt 解锁 / 屏幕唤醒
        System->>IM: screensDidWake / screenIsUnlocked
        IM->>IM: isLocked = false
        IM->>SRM: onLockStateChanged(false) [Task异步]
        IM->>SRM: systemDidWake → handleSystemWake() [同步]
        
        Note over SRM: handleSystemWake 先执行（同步）
        Note over SRM: handleLockStateChanged(false) 后执行（Task异步）
    end
```

### 9. handleSystemWake 唤醒处理详细流程

```mermaid
sequenceDiagram
    participant SRM as SmartReminderManager
    participant IM as InputMonitor
    participant Overlay as ReminderOverlayWindow
    
    SRM->>SRM: handleSystemWake()
    SRM->>SRM: lastActivityCheckTime = now
    
    alt isResting && 蒙版正在显示
        Note over SRM: 休眠时蒙版开着
        SRM->>SRM: 停止所有定时器
        SRM->>SRM: isResting=false, activeDuration=0
        SRM->>IM: refreshActivity()
        SRM->>SRM: startTimer()
        Note over SRM: 重置为新的工作周期
    else isWorkPaused && !isResting
        Note over SRM: 工作暂停状态
        SRM->>SRM: activeDuration = pausedActiveDuration
        SRM->>SRM: isWorkPaused = false
        SRM->>SRM: idleStartTime = nil
    end
    
    SRM->>IM: refreshActivity()
    SRM->>SRM: 重启主定时器
    
    alt isResting && restStartTime 存在
        SRM->>SRM: 计算剩余休息时间
        alt remaining > 0
            SRM->>SRM: 重启 restTimer(remaining)
            SRM->>SRM: showRestOverlay()
        else remaining <= 0
            SRM->>SRM: handleRestEnd()
        end
    end
```

### 10. handleLockStateChanged 锁屏状态处理

```mermaid
sequenceDiagram
    participant SRM as SmartReminderManager
    participant Overlay as ReminderOverlayWindow
    
    alt locked = true（锁屏）
        SRM->>SRM: idleStartTime = now（如果还没设置）
    else locked = false（解锁）
        alt idleStartTime 存在
            SRM->>SRM: 计算 elapsed = now - idleStartTime
            
            alt elapsed >= restRecognitionTime
                Note over SRM: ✅ 充足休息（如盒盖很久）
                SRM->>SRM: activeDuration = 0
                SRM->>SRM: idleStartTime = nil
                SRM->>SRM: lastActivityCheckTime = now
                SRM->>Overlay: overlayState = .restComplete
                SRM->>Overlay: message = "休息时间结束了！..."
                SRM->>Overlay: show()
                SRM->>SRM: playSound(restEndSoundName)
                Note over Overlay: 显示"休息完成"蒙版
            else elapsed < restRecognitionTime
                Note over SRM: 短暂锁屏，不做特殊处理
                SRM->>SRM: idleStartTime = nil
            end
        else idleRecognized = true
            SRM->>SRM: activeDuration = 0
            SRM->>SRM: idleStartTime = nil
        else
            SRM->>SRM: idleStartTime = nil
        end
    end
```

## 关键时间参数说明

| 参数 | 默认值 | 说明 | 可配置 |
|-----|--------|------|--------|
| workDuration | 2700秒（45分钟） | 工作时长，达到后触发休息提醒 | ✓ |
| restDuration | 300秒（5分钟） | 休息时长，倒计时结束后提示继续工作 | ✓ |
| idleThreshold | 60秒 | 空闲阈值，超过后认定为用户离开 | ✓ |
| restRecognitionTime | 270秒（4分30秒） | 休息认定时间，超过此时长认定为充分休息 | ✓ |
| Timer间隔 | 1.0秒 | 主定时器间隔，用于活动检测和时间累加 | ✗ |
| 音频检测启动延迟 | 15秒 | 空闲多久后才开始音频检测 | ✗ |
| 音频检测窗口 | 5秒 | 连续检测音频输出的窗口时间 | ✗ |

## 通知机制

### 发送的通知

| 通知名称 | 触发时机 | 携带数据 |
|---------|---------|---------|
| SmartReminderEnabled | 启动智能提醒时 | 无 |
| SmartReminderDisabled | 停止智能提醒时 | 无 |
| SmartReminderStateChanged | 每秒状态更新 | isResting, activeDuration, idleTime, workDuration, restDuration, restStartTime, hasPermission |

### 接收的通知

| 通知名称 | 来源 | 处理 |
|---------|------|------|
| .systemDidWake | InputMonitor (screensDidWake) | SmartReminderManager.handleSystemWake() |
| screensDidSleepNotification | NSWorkspace | InputMonitor → onLockStateChanged(true) |
| screensDidWakeNotification | NSWorkspace | InputMonitor → onLockStateChanged(false) + systemDidWake |
| com.apple.screenIsLocked | DistributedNotification | InputMonitor → onLockStateChanged(true) |
| com.apple.screenIsUnlocked | DistributedNotification | InputMonitor → onLockStateChanged(false) |

## 数据持久化

### 保存的状态

```json
{
    "activeDuration": "TimeInterval — 当前累计活跃时间",
    "isResting": "Bool — 是否在休息中",
    "restStartTime": "TimeInterval — 休息开始时间（Unix时间戳）"
}
```

### 保存时机
- 应用退出时（通过 AppDelegate）

### 恢复时机
- 应用启动时调用 start() → restoreState()

```mermaid
        else 启用 → 禁用
            SRM->>IM: stopMonitoring()
            SRM->>SRM: stopTimer()
        end
    else 空闲阈值变更
        SRM->>IM: updateIdleThreshold(newThreshold)
    else 工作时长变更
        SRM->>SRM: lastActivityCheckTime = now
    else 休息时长变更（休息中）
        SRM->>SRM: 计算新的剩余时间
        SRM->>SRM: 重启 restTimer
        SRM->>SRM: showRestOverlay() 刷新蒙版倒计时
    end
```

## 边界情况处理

### 1. 盒盖休眠后唤醒
- **场景**: 用户合上盖子很久后打开
- **处理**: `handleLockStateChanged(false)` 检测 elapsed >= restRecognitionTime → 显示"休息完成"蒙版 + 重置 activeDuration

### 2. 休眠时蒙版正在显示
- **场景**: 蒙版显示中用户合盖休眠
- **处理**: `handleSystemWake` 检测 isResting && isVisible → 直接重置为新工作周期

### 3. 时间跳跃
- **场景**: 系统时间变更或休眠后时间跳跃
- **处理**: 唤醒时更新 lastActivityCheckTime，使用相对时间计算

### 4. 权限缺失
- **场景**: 无辅助功能权限时无法监测键鼠输入
- **处理**: 菜单栏显示"未授权"，提供权限设置引导

### 5. 快速开关
- **场景**: 用户快速开关智能提醒
- **处理**: didSet 中完整停止/启动监听和定时器

### 6. 视频/音频模式
- **场景**: 用户离开键鼠但在看视频/听音乐
- **处理**: 空闲 15 秒后启动音频检测，连续 5 秒有音频输出 → 进入视频模式，暂停工作计时

### 7. 休息中配置修改
- **场景**: 休息中修改休息时长
- **处理**: 计算新的剩余时间，重启休息定时器，刷新蒙版显示
