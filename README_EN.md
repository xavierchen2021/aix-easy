# Floating Button App

A minimalist productivity tool for macOS that provides quick access to notes, clipboard management, and smart reminders through a floating button interface.

## Features

- **Floating Button**: Always accessible floating button that stays on top of other windows
- **Quick Notes**: Instant note taking without switching applications  
- **Clipboard History**: Manage and access your clipboard history
- **Smart Reminders**: Automated reminder system based on usage patterns
- **Customizable**: Highly configurable appearance and behavior
- **Lightweight**: Minimal system resource usage

## Installation

### From Source
1. Clone the repository: `git clone <your-repo-url>`
2. Open in Xcode
3. Build and run

### Binary Release
Check the [Releases](https://github.com/yourusername/floating-button-app/releases) page for pre-built binaries.

## Usage

The floating button can be moved around the screen and provides quick access to:
- Note taking interface
- Clipboard history
- Settings panel
- Reminder management
